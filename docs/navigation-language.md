# 导航与界面语言契约

## 导航语义

Foundation 拥有导航目的地的产品含义、用户可见名称、图标语义、顺序和未读聚合方式；客户端拥有实际路由地址与平台原生导航组件。

- Web 将发现、动态和搜索作为主要浏览入口；通知、私聊和收藏作为登录后的账户快捷入口，发布与个人资料保持独立入口。
- Flutter 使用发现、动态、发布、消息、我的五个主目的地；消息下分通知与私聊，并聚合两者未读数。
- 选中态不更换目的地含义或另造图形，只改变容器、前景色和平台允许的强调方式。

## 稳定词汇

主题帖、子贴、楼层、回复、动态、通知、私聊和收藏是用户认识的内容名词。发布、保存、删除、隐藏、恢复、重试、取消和关闭是稳定动作词。

- 同一动作从入口、确认、pending 到完成反馈保持同一动词。
- 客户端可以编写符合上下文的完整句子，但不能用协议名、内部枚举、数据库概念或近义宣传词替换稳定词汇。
- 后端字段名与路由段不受本契约约束；它们不得反向决定界面语言。

具体标签、目的地矩阵和词汇表以 `contracts/foundation.v1.json` 的 `experiences.navigation` 与 `experiences.language` 为准。
