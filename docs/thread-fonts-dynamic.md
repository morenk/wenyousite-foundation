# 动态主题正文字体

本文是已授权动态字体工作的行为规范与验收准备，尚未绑定 Backend 新契约提交，不能作为已实现接口或消费者接入凭据。HTTP、Markdown、能力声明、状态字段、错误码、分页和缓存时效的精确定义，待 Backend 提交后从同一 SHA 整体同步。本文不创建运行时目录、ID 白名单或另一套机器契约。

[既有规范](thread-fonts.md)固定的正文 v1 与运行策略 v2 继续作为兼容依据。该运行策略 v2 的固定 28 款快照，与新增动态正文协议是不同概念；不能因为版本名称相似而拼接策略。现有原字节测试镜像不覆盖、不改义。以下动态行为仅适用于完成新协议协商的消费者，未完成接入时保留已验证的旧路径。

## 版本身份与正文

管理员发布客户端构建后才创建的字体版本，Web 与 Mobile 应在同一会话获得并使用，无需逐款改代码、重新构建或安装 APK。家族用于组织和选择；正文绑定不可变版本身份，不绑定名称、排序、当前目录位置或“最新版”。第二版发布及目录回滚只影响后续选择，不能让旧帖、草稿或历史复制源自动换成另一版。

新增正文版本身份的属性语法及与 v1、颜色、剪贴板的组合，等待 Backend 精确契约。客户端不将版本 ID 编译为枚举，不以当前目录包含与否决定历史内容是否可解析；格式不合法与语法合法但尚未知的版本须分开处理。未知版本的原文字、身份及其他合法格式保留，显示先回退系统字体并按需解析身份；无法保源时阻止有损覆盖，不能静默移除标记再保存。旧端读取使用兼容投影，写入保护须覆盖创建、编辑、草稿和聚合保存等实际入口。

28 款历史字体可通过可重跑导入建立固定映射，重复导入不另造历史身份、不改写 v1 资源与旧帖。小城继续退役，不通过导入或旧缓存恢复为可选项。未知或撤回内容的保源，不授予新选、下载或渲染权限。

UI、标题以及列表、搜索、消息、动态和分享摘要使用默认字体，零自定义字体下载／注册；已有缓存也不应用于这些场景。主题正文与编辑的局部选择、颜色和粗斜删、链接、撤销、输入法及阅读锚点仍遵循共享体验。

## 状态与粘贴

下表描述业务含义，不预设 Backend 状态枚举或响应结构。

| 状态或动作 | 新选与本次粘贴片段 | 已有正文与草稿 |
| --- | --- | --- |
| 已发布且获准使用 | 可按目标能力保留该不可变版本；资源暂未下载不等于身份未知。 | 按需取得相同版本，资源到达前保源回退。 |
| 停用 | 禁止新选；粘贴片段去掉该字体，保留文字与受支持格式。 | 停用本身不撤回历史渲染许可；仍绑定原版本，不能升级或清理标记。 |
| 撤回 | 禁止新选、下载和渲染；粘贴片段去字体。 | 保源并显示系统字体；缓存、已注册 face、迟到下载或旧目录都不能恢复渲染许可。 |
| 语法合法但身份未知 | 未确认获准前不引入本次粘贴内容，片段去字体。 | 保留身份和文字，合并按版本查询；查询失败不改写源内容。 |
| 目录回滚 | 后续选择按回滚后的有效目录执行，仍服从停用／撤回状态。 | 不改已保存版本，不将旧目录当成撤回解除。 |

过滤只发生在本次粘贴片段入口：保留目标支持的颜色、粗体、链接等格式，以及片段中其他仍获准使用的字体。不得把该过滤放进共用正文解码、编辑回填或草稿恢复。动态等不支持字体的目标去全部字体。Mobile 系统剪贴板仍按既有纯文本边界处理；只有已验证的受支持结构化路径才恢复格式。停用／撤回／未知的精确写入与能力协商规则由 Backend 契约决定，消费者不得因本地允许保存而绕过服务端保护。

## 同会话发现与恢复

轻目录只用于发现与选择，缩略样张不要求加载全部字体。每个版本的描述符、分片清单及实际字符资源按需获取，不因目录扩充、打开选择器或最近使用而预下载全集。发现结果按不可变版本引用内容哈希资源，不能覆盖旧哈希路径。

动态目标要求每 5 分钟元数据再验证，并在回到前台、打开选择器和遇到未知版本时合并相关请求；按版本点查与短期负缓存避免同一未知身份形成请求风暴。ETag、每页最多 200 项的分页以及负缓存期限须按新契约实现，不能将缺页、失败或旧负缓存当成全量删除；分页或刷新过程中也不能暂时放开已知撤回。新发布版本不能被永久负缓存挡住，需验证缓存到期及契约规定的失效路径。

失败时继续使用最后一次验证通过且仍获准的结果，正文立即可读，重试静默进行。已经明确获知的撤回优先于旧目录、离线缓存及迟到结果；离线且尚未获知的服务端变化不能声称已经同步。目录版本变化不清空网络窗口、退避、Retry-After、资源隔离或原生尝试记录。既有慢链路进度超时、取消、请求合并、元数据限长及窗口恢复须由新策略明确承接，不能仅因目录变大而放宽。

## 动态资源账本

本节数字为本轮已授权目标，等待 Backend 以新机器契约承载；不能用于改写既有固定快照策略镜像或放宽旧消费者。

Web 不以固定家族数量阻断后续阅读，仍以可见 lease 管理活动资源，维持 64 faces／16 MiB SFNT 输入估算边界。仅实际解除无引用资源的持有后归还相应驻留额度；不同家族与版本共享相同账本，目录更新不另开额度。输入估算不是浏览器 RSS 上限，需重复浏览实测。

Mobile 改为同一 FlutterEngine 内持续追加的注册账本，以 SHA＋family 去重；累计输入最多 64 MiB、最多 1,024 个键，包含失败的原生尝试，服务端只能收紧本地上限。原生调用前记账，成功复用、失败隔离，路由、目录、版本刷新和磁盘淘汰不清零；同 SHA 的不同 family 仍分别承担注册成本，不能生成别名绕过去重。达到上限时静默使用默认字体并保源，无弹窗要求重启，无假卸载；该有限账本不承诺无限次原生加载。下载失败而尚未调用引擎与原生调用失败须分别处理。

64 MiB 输入是累计原生注册输入的边界，不是 RSS、下载窗口或磁盘缓存大小。64 MiB 磁盘缓存独立计账；淘汰文件不释放注册账本。旧固定快照的 256 MiB 接受边界不能用于新的追加模式。需要在同一引擎跨目录／版本反复浏览，分别提供输入、注册键、失败占用、下载缓冲及实际内存走势。

## 管理与发布体验

管理员上传单个 TTF／OTF 并填写名称、语言、排序、作者、来源及授权材料，预览处理结果后发布。上传目标为不超过 64 MiB，不接受 ZIP、TTC、彩色字体或 URL 抓取；可变字体允许固定默认实例。分发、转码及分片权限不足时停留草稿，不进入处理或发布。状态展示应准确区分待处理、处理中、失败、待发布与已发布，不能把缩略图生成成功等同于字库可用。

私有暂存、持久任务与独立 Worker 由 Backend 实现；解析使用无网、非 root 隔离环境，目标为单并发、10 分钟和 2 GiB 资源边界。源 SHA、处理参数和工具链共同决定去重，重试不重复发布或覆盖旧对象。生成覆盖信息、许可声明、缩略样张及两端资源时保留必要排版字形；处理成功后仍须验证发布资源可读，才能原子发布目录。管理权限、紧急撤回的加强验证、CSRF 和审计复用既有机制，预览不触发公开发布，不自动清理历史产物。

## 跨仓验收用例

下列 ID 用于关联各仓真实测试与交付记录，不是接口字段或机器夹具。新契约落定后补充生产者原字节镜像，再将精确输入／输出与这些行为关联。

| 用例 ID | 必须观察的结果与证据 | 执行责任 |
| --- | --- | --- |
| `dynamic-after-build` | 记录客户端构建 SHA／时间，之后才创建并发布此前不存在的新版本 ID；同一浏览器会话及 Android 引擎发现、选择、发帖、结构化复制、保存重开均成功，无改代码或重建。 | Backend／Web／Mobile |
| `immutable-second-version` | 再发布同家族第二版；新选可用第二版，旧帖与旧草稿仍解析第一版，回滚目录不改历史绑定。 | Backend／Web／Mobile |
| `repeatable-legacy-import` | 重跑 28 款导入映射一致，v1 字节及旧资源路径保留，小城仍退役。 | Backend |
| `unknown-preserved` | 合法未知身份经历断网、点查失败、草稿恢复和编辑往返后保留文字／身份／其他格式；不能保源时覆盖写入被阻止。 | Backend／Web／Mobile |
| `old-client-projection` | 使用真实旧能力组合验证安全投影与各写入入口拒绝有损覆盖，不能只验证新端成功。 | Backend／Web／Mobile |
| `disabled-vs-withdrawn` | 停用禁止新选而保留历史渲染；撤回禁止下载和渲染，覆盖缓存命中、已注册 face、离线后的已知状态及迟到响应，正文仍保源。 | Backend／Web／Mobile |
| `paste-state-filter` | 混合可用／停用／撤回／未知版本粘贴到新旧主题，仅保留获准字体及目标支持格式；原帖解码、编辑、草稿保源；动态去全部字体。 | Web／Mobile |
| `catalog-refresh` | 验证定时再验证、前台／选择器／未知版本合并、ETag 与分页；超过 200 项仍能发现，失败或缺页不删除已验证身份、不恢复撤回。 | Backend／Web／Mobile |
| `negative-cache-recovery` | 重复未知查询有界，负缓存按契约到期或失效后可发现新发布版本；断网恢复静默重试，无永久未知锁。 | Backend／Web／Mobile |
| `summary-zero-fonts` | 列表、搜索、消息、动态和分享摘要在冷／热缓存均默认字体，零自定义字体请求与注册，源正文不变。 | Web／Mobile |
| `thumbnail-selection` | 大目录、切语言和最近使用只获取所需元数据／缩略图，无完整字库批量加载；明暗窄屏能辨识名称、状态及真实样张。 | Web／Mobile |
| `ledger-across-releases` | 连续发布及切换目录不重置窗口、重试、隔离和注册账本；跨版本相同 SHA 去重，网络失败与原生失败区分。 | Web／Mobile |
| `web-residency` | 无固定家族数截断，64 faces／16 MiB 边界、可见 lease、实际释放后回收和重复阅读内存均有证据。 | Web |
| `mobile-append-limit` | 同引擎追加直到输入或键数边界，成功／失败占用持续保留，同 SHA 多 family 分别计账，超限静默回退；报告 Android 网络、剪贴板和实际内存，不以输入预算冒称 RSS。 | Mobile |
| `slow-transfer-retained` | 新目录发现与资产下载仍遵守流式限长、合法进度续期、总截止、真正取消、预算不退款及窗口自动恢复，重复请求有界。 | Web／Mobile |
| `upload-processing-publish` | 无授权或非法上传不能处理发布；隔离 Worker 超时／超内存／失败及重试有界；处理后先验资源可读再原子发布，重复任务不覆盖历史产物。 | Backend／Web 管理端 |
| `admin-withdraw-audit` | 上传、预览、发布及紧急撤回按管理权限、加强验证、CSRF 与审计执行，失败不留下可见的半发布目录。 | Backend／Web 管理端 |

写入验收必须使用本轮登记的独立 PostgreSQL、Redis、存储及账号，记录环境身份、源码版本、runId、失败路径与清理结果；清理失败仍为验收失败。禁止公网业务写入。Web 提供明暗／窄屏真实画面；Mobile 在 Windows 提供 Android 同会话证据。未执行的用例明确列出，Foundation 文档、Schema 或夹具检查不代替消费者运行、视觉或内存验收。

## 契约接入待办

收到 Backend 新 SHA 后核对正文身份与旧能力投影、停用／撤回写入保护、目录与按版本发现、缓存失效及范围校验策略；将生产者原字节 Schema／夹具和来源摘要纳入独立测试组，保留旧镜像回归。动态测试不能继续把 28 款或固定快照当作上限，须验证构建后新身份及边界拒绝。执行 Foundation 检查与打包门禁，核验动态业务数据不进入运行时导出。

本阶段不创建 API 样例、猜测错误码或负缓存时长，不把上述场景做成假执行器。不改变 Foundation 机器体验契约、Token、包版本或正式 Tag；消费者仍锁定已发布依赖，直接固定 Backend 已提交契约。协议接入与真实验收完成前，本动态切片保持待接入状态。
