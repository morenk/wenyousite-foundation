# Flutter profile

- Android 8+ 手机竖屏优先，共享代码保持 iOS 可兼容；不复制桌面三栏与固定侧栏。
- 使用与 Web 同源的亮色与黑夜语义色板、品牌角色和三种系统排版角色；Flutter 通过 `WenyouFoundationTheme` 映射系统亮度与本机显式偏好，不在业务页面复制色值。
- 默认跟随系统外观，允许用户在本机选择亮色或黑夜；切换不改变单列布局、信息顺序、图片呈现或触控尺寸。系统栏、原生控件、浮层和全屏图片查看同步解析后的主题。
- 原生启动层只显示 96dp 品牌标识与柔粉底色；Flutter 第一帧补齐名称、品牌文案和状态。认证入口与首页标题栏分别使用 48dp、24dp 标识。
- 页面默认保持单列；动态主信息流是唯一正式领域例外，可使用双列瀑布流。360–400dp 使用 12dp 外边距，401–599dp 使用 24dp，600dp 以上限制内容宽度。
- 列表容器和列表行占满单列可用宽度；消息气泡、标签、徽标和紧凑操作按内容收缩不属于列表卡片。
- 所有可点击控件命中区不小于 48×48dp；保留系统安全区、文字缩放、软键盘滚动和系统返回。
- 正文与元数据元素消费 `experiences.elements` 的移动 profile；轻量内联元素可以随文本排版，独立可点击标签仍保留 48dp 命中区，非交互徽标不伪造触控面积。
- 可点击主题标签只显示 `#` 与粉色品牌文字，不使用底色、描边、圆角或胶囊包裹；透明命中区仍满足 48dp，并保留焦点与可访问性语义。
- 骰子节点无图标并保持原子不换行；可见结果固定为 `{notation} = {total}`，完整逐骰明细进入 Semantics，按 `nodeId` 绑定服务端结果。
- 页面宽度、边距断点和语义排版消费移动 profile；不在业务页面复制 401dp 边距切换或内容宽度上限。
- 列表项标题使用 body 600；详情内容标题、内容页面与区块结构标题使用 display 500；设置与管理界面的各级标题及管理中的内容名称使用 body 600，字号与行高复用对应标题角色。弹层、状态、控件、用户名和富文本标题保持 body；数字、时间与计数保持 utility。三个角色都使用系统字体，角色含义保持不变。
- 普通内容列表与详情不足 72 小时显示相对时间；之后及未来时间同年显示 `MM-dd`、跨年显示 `yyyy-MM-dd`，Semantics 通过 `formatWenyouDate` 提供完整日期，不含时分。安全、审计、温油账务、预约和到期时刻直接显示完整时刻，已有秒精度不得降低；详见 [时间与数字](../presentation.md#时间与数字)。
- 个人资料身份区不显示邮箱验证状态；未验证用户仍可从账号安全页或受限操作引导进入验证流程。
- 按钮、输入、选择与页签使用 `WenyouFoundationMobile.radiusControl`（8dp），Dialog、Popover、Sheet、菜单使用 `radiusPanel`（12dp）；非胶囊小表面与独立图片使用 `radiusCompact`（8dp）。“我的温油”等页面的独立内容区块使用 `radiusCard`，其中的操作仍按控件角色。头像、图标状态层保持圆形，语义 Badge 保持胶囊；48dp 命中区、安全区与文字缩放不变。
- 内容卡片与列表外框使用 `WenyouFoundationMobile.radiusCard`（10dp），独立内容卡片之间使用 `WenyouCollectionContract.cardGap`（8dp）；动态瀑布流的横纵间隔一致。连续列表行沿用分隔线，不加入卡片间距；封面和骨架跟随外框裁切，卡片内部留白与 48dp 触控下限不变。
- 卡片使用当前主题的内容表面、细边框和圆角区分层次，不用粉色页面底、纯黑大底或常驻阴影制造层级。
- 正文分隔线在阅读态与编辑态都使用正文可用宽度 50% 的居中短线圆点；楼层、评论和列表项继续使用各自的满宽结构线或区带，两者不得互换。
- 阅读态与编辑态正文统一使用 17sp、1.8 倍行高并跟随系统文字缩放；紧凑长文编辑器正文水平内边距可降到 4dp，常规创作面板使用 16dp。
- 内容编辑器支持 `page`、`expandableSheet` 与 `inline` 三种承载面；三者复用同一 WYSIWYG 文档、能力与保存语义，不能因为承载面紧凑而退化为 Markdown 源码输入。
- 软键盘可见时，编辑工具栏 dock 在键盘上方并跟随可用视口重新布局；核心工具响应式保持单行且禁止横向滚动。额外宽度依次提升正文草稿、引用、分隔线和表情包，提升项不再重复出现在“更多”中，其余能力在编辑器内部 inline 展开，不打开夺走正文焦点的独立格式面板。
- inline“更多”展开、收起或执行格式动作时保留正文选区、输入焦点与软键盘；提及由上下文候选触发，表情包入口按账号能力出现。
- 普通段落与 H2/H3 的居中、居右使用 inline“更多”中的两个独立 Toggle；居左隐式默认，再点已选按钮恢复居左，互斥切换与混合选区按[共享编辑器规则](../foundation.md#编辑器)处理。格式与段落 Toggle 的选中态按同一规则消费 `accentedBackground`、`onAccentedBackground` 与 `radiusControl`，每个按钮仍满足 48dp 命中区。内联原子内容随父段落排版，列表、引用和分隔线不参与段落对齐；独立图片按后端 Markdown v5 的既有图片语义读取与往返。
- Markdown 与 Quill Delta 转换、阅读 Widget、实际编辑事务及复制结果共同遵循共享正文边界验收用例；保留已有无前置空行的合法对齐显示，多轮保存重开不丢失逐块对齐、可见文字或空白行，也不增殖隐藏标记；普通正文内部及行首、行尾的实际连续空格保留，继续遵循系统文字缩放和单列容器，不以跨端逐像素对齐覆盖原生排版。
- Flutter Quill 编辑态的行内代码必须保持等宽字体、0.88em 字号、中性颜色和 0.35em 圆角；因渲染器没有公开精确 em 内边距接口，背景边界允许使用 Quill 原生范围。阅读态和其他平台仍精确使用元素合同的 0.12em/0.35em 内边距。
- 可交互图片进入全屏查看路由，保留系统返回、双击/捏合缩放与放大后平移；未放大时才允许下滑关闭。 主题帖与动态图集遵循 [全屏图集业务接入](../images.md#全屏图集的业务接入)：各子贴、回复讨论和动态正文/评论分组明确，关闭恢复原阅读位置；放大后仅平移，双指结束不转为翻页或关闭。
- 核心导航、操作、编辑器能力与常见状态使用 Foundation 同源 Lucide SVG；品牌标识消费 Foundation 品牌资源，分类标记、插画和操作系统专属动作可以保留平台资产。
- 除[共享编辑器规则](../foundation.md#编辑器)限定的格式与段落 Toggle 外，图标 Toggle 的静止容器透明；点赞、收藏与主题帖订阅保持同一 Lucide 路径，选中后分别使用实心鲜粉、实心金色与实心品牌深紫。图标命中区的按压状态层使用 15% 当前图标色，不能扩展到辅助文字或计数；图标按钮由控件提供稳定名称和 toggled 语义，装饰图标不重复朗读。
- 主贴管理的发言权限复用相邻设置行和现有通用选项 Sheet，纳入既有自动保存、离开等待及失败/冲突反馈；不新增权限专属面板或保存按钮。长选项与说明允许自然换行，在小屏和较大字体下保留完整内容、单列布局、48dp 命中区、安全区与系统返回，行为边界见 [共享主贴管理设置](../foundation.md#主贴管理设置)。
- 移动端阅读进度、手动快翻和自适应阅读滑块属于 Mobile 产品实现，由 Mobile 的 `ReadingScrollSpec` 管理状态、尺寸、阈值、时序、手势竞争及专属可访问性语义；Foundation 不发布这些产品专属常量。实现仍消费 Foundation 的通用主题 Token、动效尺度、普通表单滑块与无障碍基础。
- Snackbar 只承载短暂确认；加载失败、权限受限和需要重试的结果保留在原任务上下文。浮层使用 Foundation elevation 角色，并保留安全区与系统返回。

UI 与默认正文的 v7 接入只在 Windows 完成：等待正式 Tag 后独立升级依赖，移除旧捆绑字体注册、资产声明和家族名常量引用；`WenyouFoundationTypography.mobileFamilies` 只返回 body/display/utility 语义角色，结合 sizes、lineHeights、weights 映射到继承平台默认字体的 TextStyle，不设置自定义 fontFamily/fontFamilyFallback，也不把 `system-ui` 当作 Flutter 字体名。设置与管理标题仍选择 body 600，保留 pageTitle 等角色映射。验证中文与中英混排、数字、长标题换行、编辑与阅读、品牌文字、双倍文字缩放、单列布局、48dp 触控和安全区；本 Foundation 任务不代表已完成消费者升级或 Flutter 真机验收。

## Android 下载兼容

- 更新流程遵循[共享下载规范](../app-downloads.md)；`/meta.mobileCompatibility.android.updateUrl` 继续是目标构建的文件 URL，不能替换成 Web 页面。保留 HEAD 预检、GET 下载、元数据、大小、摘要、包名、构建号和签名校验，地址迁移不降低安装门禁。
- [每日下载次数](../app-downloads.md#每日下载次数)保留无 Cookie 旧 APP 直接 HEAD／GET 的兼容，不能要求先访问 Web、额外查询信息或新增 Cookie 支持；有效文件 GET 受来源 IP 北京时间每日 10 次限制。HEAD 预检次数／字节但不预留，拒绝后停止本轮下载，成功后 GET 仍可能竞争失败；预占前拒绝／失败不计次但仍计请求频率。成功预占后中断或失败均不退还，重试再次获准 GET 会计新一次。消费端可按固定 Backend `X-Download-Limit-Reason` 区分浏览器／共享 IP 次数与其他限流原因，遵守 `Retry-After`；HEAD 无正文，原因缺失时按状态兜底，不要求旧端识别新头才能下载。
- 限流遵守 `Retry-After`，暂不可用在更新上下文反馈；不循环请求、不回退源站或改装其他构建。强制更新失败继续保持原阻断策略，普通下载失败不被误报为已安装或无需升级。
- 控件沿用 Flutter 48dp 触控下限、单列、系统文字缩放和安全区；不因 Web 入口新增独立更新历史页面。窄屏浏览器的外观菜单直接下载由 Web profile 负责，不改变 Flutter 既有更新流程。
- 移动设备访问 Web 的首次下载提示属于 Web 浏览会话，不在 Flutter 再加启动弹窗、不复用 App 更新提示记录；Android 的下载动作与 Web 菜单共用流程，iOS 明确只提供 Android 包并允许继续网页。
- Windows Mobile 任务验证已安装旧 APP 的 HEAD／GET／安装与发布工具；Foundation 用例通过不等于真机或签名发布验收。本次沿用现有正式 Foundation 依赖，无需新 Tag。

## 更新前与升级后提醒

- Android 更新前／升级后弹窗遵循 [共享更新说明规范](../mobile-releases.md)，直接显示目标或实际安装版本的摘要与完整条目。保持单列和系统字体，长说明自然换行并可滚动；不以缩字、固定高度或横向滚动挤入窄屏。
- App 移除独立“查看更新”按钮、说明／版本历史页面及设置和游客“我的”中的历史入口；旧地址按原生导航规则安全返回可用入口，不留下空壳页面。推荐与升级后弹窗可明确关闭并恢复原任务，强制更新的系统返回继续受既有策略约束。
- 推荐按目标平台与构建号去重，并保留旧忽略记录；升级后按实际安装平台与构建号在本机持久去重，不因 Widget／路由重建、冷启动、账号切换或文案 revision 修订重复弹出。失败不误记已展示，待提示不能因基线更新而丢失。
- Android 无本机记录的首次迁移可复用 `package_info_plus` 的 `installTime`／`updateTime`；[10.2.1 Android 实现](https://raw.githubusercontent.com/fluttercommunity/plus_plugins/package_info_plus-v10.2.1/packages/package_info_plus/package_info_plus/android/src/main/kotlin/dev/fluttercommunity/plus/packageinfo/PackageInfoPlugin.kt)分别读取 `firstInstallTime`／`lastUpdateTime`。两者有效且更新时间更晚时提示当前已安装版本，不推测旧构建；相同时间不弹，缺失或无效只建立基线。同构建覆盖安装可能触发首次迁移提示，但建立平台／构建记录后不因重装再次触发；实际设备返回值及边界仍由 Mobile 验证，不为此新增原生通道或依赖。
- 展示协调者在前台安全时机串行处理：先强制，应用可用后升级后提醒优先，推荐择后且不叠窗。使用实际安装包身份核验说明，跨多版只提示本次安装版；强制使用不可关闭的弹窗／启动门禁容器，直接显示完整说明，系统返回、遮罩和任何一次性记录都不能解除阻断。
- 下载、关闭和重试控件保持既有触控下限与安全区，文字缩放后仍能读完整内容并执行动作。亮色与黑夜均检查长说明、错误态、读屏顺序、焦点恢复及弹窗优先级；推荐与升级后说明失败可关闭／重试，不阻断普通启动。强制说明失败保留重试与原更新动作，弹窗持续阻断且不可关闭。
- 本规范不要求升级 Foundation 依赖；功能接入、实际画面、真机及发版预检验证只由 Windows Mobile 任务完成，不扩展 iOS 发版或新增推送。

## 主题帖正文字体

动态接入另遵循[动态字体规范](../thread-fonts-dynamic.md)：正文能力 2 与运行策略 v3 分别协商，三个状态权限独立；目录／描述符再验证，本站版本状态网关控制资源，撤回优先于缓存。下文固定 28 款与运行策略 v2 只用于旧协议兼容，不能作为动态身份白名单或预算。同会话激活 v2 后，已映射 v1 标记同走 v2 描述符／状态网关，能力缺失／false／失败不回退旧通道，已知撤回始终优先，原 v1 标记保留。动态引擎账本按 SHA＋family 追加，累计输入 64 MiB／1,024 键，含失败占用；超限静默默认，目录刷新不重置，不复用旧固定快照 256 MiB 边界。

中文／日文／英文分组按[共享语言分组规则](../thread-fonts.md#语言分组)消费 Backend `designLanguage`（`zh`／`ja`／`en`）；缺失或未知值保留未分类／系统回退；不硬编码研究别名或按字符覆盖猜语言。切换分组保持选区和本地选择上下文，不自动加载整组字体。

- 遵循[共享正文字体规则](../thread-fonts.md)，复用正文样式区域，在可用高度内单列滚动；保留 48dp 命中区、安全区、系统文字缩放、软键盘和系统返回。名称和状态继承 UI 系统字体，样字预览与正文的字体仅作用于相应文本。
- 只按 Backend 的 Mobile 资源记录下载、校验并注册需要的家族，两端选择相同固定字符分片，Mobile 使用自己的 SFNT 文件和每片唯一 family 构造 fallback，不将 Web CSS 家族名作为 Flutter 注册名；不把首批全部家族打入安装包，也不在启动或打开选择器时全部注册。字体文件、解码缓冲和已注册字体分别记录成本；不能把删除磁盘缓存描述为已释放引擎字体内存。旧策略保持原累计限制；显式协商的新策略分别控制窗口网络速率、串行下载和固定已核验快照的注册。hash＋family 在同一 FlutterEngine 内最多一次原生尝试，调用前预占记账，原生失败隔离且不返还尝试资格；成功的资源持续复用，目录刷新不能无限扩充注册集合；离开页面或删除磁盘缓存不卸载原生字体。快照输入上界不能当作 RSS 上限。临时故障按资源退避，联网／前台／仍可见需求恢复时静默唤醒；不要求刷新、重启或新增 UI。
- 下载、注册和排版异步完成时保留当前阅读内容、选区及输入法组合状态；长列表更新高度测量并保持可见文字锚点。缺资源或离线仍显示原文；缓存清理不改草稿或已保存 `fontId`。接入和实际内存、安装包、真机验收只在 Windows 的 Mobile 任务执行。
- 主题／动态／消息列表、搜索、通知和分享预览摘要使用默认字体，不因摘要下载、注册或复用自定义 face，源正文身份保持不变。粘贴遵循[摘要与剪贴板边界](../thread-fonts.md#摘要与剪贴板)，仅经验证的本机进程内结构化复制可向主题正文保留字体；动态等目标去字体并保留其支持的格式。系统选区及跨应用剪贴板保持纯文本，未知 ID、外部 CSS 和失效载体回默认，不引入字体 URL。

当前目录仅有 28 款 `deliveryMode: subset` 分片字体；历史小城只保留正文身份，使用系统字体，不从旧缓存恢复可选项或请求原件。当前 v2 不接受原件专属字段／额外槽，旧 v1 与历史资源记录保留。

传输遵循[进度超时与取消](../thread-fonts.md#进度超时与取消)：实际请求开始计时，响应头和空块不续期，合法非空块刷新 15 秒 idle，总时长不得达到 600,000 毫秒。离屏且无共享需求或进入后台时真正取消，取消确认后才释放并发；字节／请求预算不立即退款，迟到数据不注册。旧 v1 15 秒总超时不改，元数据和资产限长不放宽。

目录／策略元数据也从首次请求计入共用网络窗口，按本地 64 KiB 预占并流式限长；manifest 按资产描述符单独计费，详情见[持续加载规则](../thread-fonts.md#持续加载与资源生命周期)。资源地址为 `null` 时不下载；manifest、许可归属、字体完整性遵循[共享加载规则](../thread-fonts.md#平台资源与成本)。使用后端派生基础样式，粗斜 marks 采用与 Web 一致的合成策略，须在 Flutter 实际引擎验收。

## 主题帖 RGB 取色

沿用正文样式 T 面板，遵循 [主题帖文字颜色](../text-color.md)。自定义取色是正文焦点规则的明确例外：先保存光标或选区并收起正文键盘，RGB 数值使用数字键盘，应用／取消后恢复正文焦点和原光标／选区；预设点选仍保留现有快捷格式体验。有效折叠光标支持先选色后输入，文字选区仍只改所选范围；输入色生命周期以机器契约为准。面板随可用高度滚动，色块与按钮保留 48dp 命中区，不新增主栏入口。显式文字色可替换行内代码的默认中性前景，背景及 Quill 原生内边距例外保持。
