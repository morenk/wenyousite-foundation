# Flutter profile

- Android 8+ 手机竖屏优先，共享代码保持 iOS 可兼容；不复制桌面三栏与固定侧栏。
- 使用与 Web 同源的亮色与黑夜语义色板、品牌角色和三角色自托管字体；Flutter 通过 `WenyouFoundationTheme` 映射系统亮度与本机显式偏好，不在业务页面复制色值。
- 默认跟随系统外观，允许用户在本机选择亮色或黑夜；切换不改变单列布局、信息顺序、图片呈现或触控尺寸。系统栏、原生控件、浮层和全屏图片查看同步解析后的主题。
- 原生启动层只显示 96dp 品牌标识与柔粉底色；Flutter 第一帧补齐名称、品牌文案和状态。认证入口与首页标题栏分别使用 48dp、24dp 标识。
- 页面默认保持单列；动态主信息流是唯一正式领域例外，可使用双列瀑布流。360–400dp 使用 12dp 外边距，401–599dp 使用 24dp，600dp 以上限制内容宽度。
- 列表容器和列表行占满单列可用宽度；消息气泡、标签、徽标和紧凑操作按内容收缩不属于列表卡片。
- 所有可点击控件命中区不小于 48×48dp；保留系统安全区、文字缩放、软键盘滚动和系统返回。
- 正文与元数据元素消费 `experiences.elements` 的移动 profile；轻量内联元素可以随文本排版，独立可点击标签仍保留 48dp 命中区，非交互徽标不伪造触控面积。
- 可点击主题标签只显示 `#` 与粉色品牌文字，不使用底色、描边、圆角或胶囊包裹；透明命中区仍满足 48dp，并保留焦点与可访问性语义。
- 骰子节点无图标并保持原子不换行；可见结果固定为 `{notation} = {total}`，完整逐骰明细进入 Semantics，按 `nodeId` 绑定服务端结果。
- 页面宽度、边距断点和语义排版消费移动 profile；不在业务页面复制 401dp 边距切换或内容宽度上限。
- 列表项标题使用 Noto Sans SC 600；详情内容标题、页面与区块结构标题使用 LXGW WenKai 500。弹层、状态、控件、用户名和富文本标题保持 Noto Sans SC。
- 列表与详情时间在 72 小时内统一显示相对时间；之后同年显示 `MM-dd HH:mm`、跨年显示 `yyyy-MM-dd HH:mm`，Semantics 提供完整时间。
- 个人资料身份区不显示邮箱验证状态；未验证用户仍可从账号安全页或受限操作引导进入验证流程。
- 卡片使用当前主题的内容表面、细边框和圆角区分层次，不用粉色页面底、纯黑大底或常驻阴影制造层级。
- 正文分隔线在阅读态与编辑态都使用正文可用宽度 50% 的居中短线圆点；楼层、评论和列表项继续使用各自的满宽结构线或区带，两者不得互换。
- 阅读态与编辑态正文统一使用 17sp、1.8 倍行高并跟随系统文字缩放；紧凑长文编辑器正文水平内边距可降到 4dp，常规创作面板使用 16dp。
- 内容编辑器支持 `page`、`expandableSheet` 与 `inline` 三种承载面；三者复用同一 WYSIWYG 文档、能力与保存语义，不能因为承载面紧凑而退化为 Markdown 源码输入。
- 软键盘可见时，编辑工具栏 dock 在键盘上方并跟随可用视口重新布局；核心工具响应式保持单行且禁止横向滚动。额外宽度依次提升正文草稿、引用、分隔线和表情包，提升项不再重复出现在“更多”中，其余能力在编辑器内部 inline 展开，不打开夺走正文焦点的独立格式面板。
- inline“更多”展开、收起或执行格式动作时保留正文选区、输入焦点与软键盘；提及由上下文候选触发，表情包入口按账号能力出现。
- 普通段落与 H2/H3 的左、中、右对齐进入 inline“更多”中的单一分段控件；内联原子内容随父段落排版，列表、引用、图片和分隔线不参与。
- Flutter Quill 编辑态的行内代码必须保持等宽字体、0.88em 字号、中性颜色和 0.35em 圆角；因渲染器没有公开精确 em 内边距接口，背景边界允许使用 Quill 原生范围。阅读态和其他平台仍精确使用元素合同的 0.12em/0.35em 内边距。
- 可交互图片进入全屏查看路由，保留系统返回、双击/捏合缩放与放大后平移；未放大时才允许下滑关闭。
- 核心导航、操作、编辑器能力与常见状态使用 Foundation 同源 Lucide SVG；品牌标识消费 Foundation 品牌资源，分类标记、插画和操作系统专属动作可以保留平台资产。
- 图标 Toggle 的静止容器透明；点赞、收藏与主题帖订阅保持同一 Lucide 路径，选中后分别使用实心鲜粉、实心金色与实心品牌深紫。图标命中区的按压状态层使用 15% 当前图标色，不能扩展到辅助文字或计数；图标按钮由控件提供稳定名称和 toggled 语义，装饰图标不重复朗读。
- Snackbar 只承载短暂确认；加载失败、权限受限和需要重试的结果保留在原任务上下文。浮层使用 Foundation elevation 角色，并保留安全区与系统返回。
