# Web profile

- 目标为 1024px 以上 PC Web；使用鼠标、键盘和浏览器缩放，不复制移动端布局。
- 画布随解析后的亮色或黑夜模式切换，社区页面保持桌面信息密度与三栏骨架；创建、消息和管理使用宽工作区。
- 默认跟随 `prefers-color-scheme`，用户可在全局导航显式选择亮色或黑夜；偏好只保存在当前浏览器。首屏脚本必须在界面绘制前解析并写入 `data-theme`，避免服务端页面先闪出错误主题；系统偏好变化只在“跟随系统”时更新界面。
- 根节点同步 `color-scheme` 与浏览器主题色；原生表单、选区、焦点、Toast、编辑器、图表、遮罩和图片查看器全部消费当前主题语义。正文图片、头像、封面和外部内容不得套用全局亮度滤镜。
- 默认控件命中区不小于 40px，紧凑工具栏不小于 32px；键盘焦点始终可见。
- 图标控件静止容器透明：未选中使用低强调紫灰描边，已点赞、已收藏和已订阅分别使用鲜粉、金色与品牌深紫实心图标。hover/focus 在图标命中区使用 10% 当前图标色圆形状态层，pressed 使用 15%；状态层不能扩展到辅助文字或计数，disabled 与 pending 消费中央状态契约。
- 正文传送门使用轻量内联胶囊，可随长标签换行且不截断；阅读态与编辑态保持同一视觉，编辑态不触发导航。普通链接、提及、代码、骰子、引用、分隔线和元数据元素消费 `experiences.elements`，不在业务模块重写近似样式；正文分隔线固定为正文可用宽度 50% 的居中短线圆点，不借用满宽卡片边界。可点击主题标签只使用粉色品牌文字，不带底色、描边或胶囊包裹，并通过悬停下划线与平台焦点语义表达可点击性，不借用点赞专色。
- 骰子节点无图标并保持原子不换行；可见结果固定为 `{notation} = {total}`，完整逐骰明细进入 `aria-label`，按 `nodeId` 绑定服务端结果。
- 页面宽度、语义排版、颜色角色、圆角、阴影、浮层层级、动效和线路色全部消费中央 Web Token，不在业务页面创建近似值。主要行动按钮使用 `actionPrimary`；柔和选中状态与低强调容器使用 `primary`；高辨识结构线和进度标记使用 `brandStrong`。
- 列表项标题使用 body 600；详情内容标题、内容页面与区块结构标题使用 display 500；设置与管理界面的各级标题及管理中的内容名称使用 body 600，字号与行高复用对应标题角色。弹层、状态、控件、用户名和富文本标题保持 body；数字、时间与计数保持 utility。三个角色都使用系统字体，角色含义保持不变。
- 普通内容列表与详情不足 72 小时显示相对时间；之后及未来时间同年显示 `MM-dd`、跨年显示 `yyyy-MM-dd`。`title` 和读屏通过 `formatWenyouDate` 提供完整日期，不含时分；`dateTime` 保留原始时间戳。安全、审计、温油账务、预约和到期时刻直接显示完整时刻，已有秒精度不得降低；详见 [时间与数字](../presentation.md#时间与数字)。
- 按钮、输入、选择和页签使用 `--radius-control`（8px）；Dialog、Popover、Sheet、Dropdown/菜单外框使用 `--radius-panel`（12px）；非胶囊小表面与独立图片使用 `--radius-compact`（6px）。`--radius` 默认别名指向 control；业务样式不得用裸 `rounded`、`rounded-2xl` 等通用档位绕过语义角色；头像、图标状态层与语义胶囊仍可使用完整圆形。
- 浏览内容卡片与列表外框使用 `--radius-card`（10px）；独立内容卡片的横纵间隔使用 `COLLECTION_WEB_PROFILE.cardGap` / `--collection-card-gap`（8px），瀑布流的测量、定位和骨架屏保持一致。连续列表行仍以分隔线组织，`StackList` 不增加行间空隙；封面贴边裁切与骨架轮廓沿用卡片圆角。
- 水平 Tabs 的结果面板、列表容器和列表行占满主内容列；多列只使用明确网格，不以内容宽度隐式分栏。
- 主题帖正文使用 17px、1.9 倍行高与 680px 文本测量宽度，对应约 40 个全角字；编辑器框架可放宽到 50rem，但正文块不能随框架继续变宽。
- 编辑器正文首列偏移 24px；工具栏外层偏移 12px，并计入首个控件自身 12px 内缩，使工具栏首项和正文首列共用基线。
- 工具栏按 `expanded`、`with-more`、`without-draft`、`compact` 四档逐级收纳，真实溢出时才显示“更多”，始终不横向滚动；菜单只列出当前档位隐藏的能力。标准与无草稿密度优先直出行内代码，将链接、列表和对齐收进“更多”；宽栏同时直出行内代码与链接，紧凑栏继续同时收纳。
- 普通段落与 H2/H3 通过一个对齐入口切换左、中、右；入口图标同步当前段落状态，混合选区不伪造单一选中态。列表、引用和分隔线不响应段落对齐命令；独立图片按后端 Markdown v5 的既有图片语义读取与往返。
- 阅读解析、Milkdown 编辑回填及输入、草稿恢复和复制粘贴共用正文协议边界语义；合法对齐块即使紧接前文也必须独立呈现，不能依赖 CommonMark 引用定义是否碰巧被识别。按共享验收用例检查多轮保存重开，内部解析分隔不能变成可见空白行。正文布局保留普通文本内部及行首、行尾的实际连续空格，不限于格式节点边界；保持自然换行，不将作者空格布局自动转换为竖排、表格或等宽字体。
- 可交互正文图和封面使用模态 lightbox 查看完整来源；支持键盘关闭与明确缩放控件，缩略图裁切不能延续到大图。
- 主贴管理的发言权限与可见范围使用同一表单字段样式和既有选择控件，纳入当前表单的统一保存、取消及未保存离开提醒；保留桌面密度、键盘选择和可见焦点，不新增权限专属弹窗或保存入口。验收查看完整设置页中的字段基线、间距和说明层级，行为边界见 [共享主贴管理设置](../foundation.md#主贴管理设置)。
- Toast 只承载短暂确认；阻塞任务的错误保留在页面或表单上下文。模态、菜单、Tooltip 和全局进度使用 `experiences.overlays.web` 的语义层级，不直接写任意 z-index。

系统字体接入须等待正式 v7 Tag，通过独立提交升级依赖：删除旧 Foundation 字体 CSS 导入、字体加载与预加载、字体依赖及手写家族覆盖，从 `TYPOGRAPHY_FAMILIES` 消费各角色的 `family` 和 `fallback`。CSS 的 `system-ui`、`sans-serif` 是通用家族关键字，须保持未加引号；字号、行高、字重和使用场景继续消费现有尺度与语义。验证桌面信息密度、键鼠焦点、中文与中英混排、数字、长标题、品牌文字及阅读/编辑换行，确认没有旧字体网络请求。数学排版与系统等宽字体按既有规则保留。

## 管理后台

- `/station` 名称为“温油站管理后台”，面向 PC 管理员的日常用户、内容、运营和系统管理。导航默认展开，按“总览、用户管理、内容管理、运营管理、举报与申诉、系统管理”组织；举报与申诉有独立入口，管理员账号仅向超级管理员开放。保留现有页面地址。
- 总览首先展示用户规模、活跃、新增和内容产出，用户活动与内容发布趋势可切换；举报待办使用紧凑入口，运行状态独立加载，失败不遮挡其他管理数据。
- 管理区使用高密度工作台，采用清晰表头、细分隔线和固定操作列，减少装饰卡片、大图标和留白。侧栏约 208px、页头约 48px、工作区内边距约 16px，表格正文约 14px，常规行约 40px、双行内容约 56px，紧凑控件命中区不小于 32px。这些是后台实现的布局与验收目标，不新增共享 Token；排版角色、语义颜色、焦点、圆角和浮层层级继续消费既有机器契约。
- 紧凑样式仅作用于后台；不改变社区前台和 Mobile，不向移动端传播桌面尺寸。页面本身不横向滚动，宽表格由自身容器承接横向滚动，并保证操作列可达。
- 每页只保留一个主标题。禁止冗余副标题、用途复述、开发术语和实现说明，不将删掉的说明转为常驻 Tooltip。字段、状态和按钮使用简短明确的功能名称；必要错误保留在相关字段或页面，操作后果在对应确认中说明。
- 用户和内容详情使用独立页面；返回列表时恢复筛选、已访问分页和滚动位置，筛选变化回到第一页。用户详情可直接进入带作者筛选的关联内容列表，账号状态操作与资料展示分区。
- 内容管理覆盖主题帖、楼层与回复、动态、动态评论；正常内容无需经过举报流程即可查询。详情复用安全正文与媒体展示，父级限制清晰显示。分类标签整理使用短表单，版本冲突保留输入，成功后刷新相关列表与详情。
- 短表单及操作确认使用弹窗；举报、申诉保持已有处理流程并统一密度。后台独立会话、权限与高风险验证仍由业务契约约束，不用视觉重构弱化安全边界。
- 在 1024、1366、1920px 宽度和亮暗模式下验收；1366×768 下普通单行列表首屏至少显示 12 条数据。检查键盘焦点、浏览器缩放、列表恢复、加载、空结果、局部失败、表单错误，以及登录、总览、列表、详情和弹窗的精简文案。
- HTTP 接口、可管理内容范围、统计口径、权限、审计与迁移的事实源归 Backend；本节只定义 Web 体验，不复制业务 Schema。兼容与交付边界见 [后台体验兼容登记](../deprecation-register.md#综合管理后台文档)。

### 后台登录与会话

- 登录表单提供默认未勾选的“记住此设备（7天）”；不增加副标题、用途复述或实现说明，不保存密码与邮件验证码。未勾选保持 30 分钟空闲、8 小时绝对期限；勾选后为固定 7 天，期间无短空闲失效，请求和重新打开浏览器不延长期限。时限及认证事实源见 [Backend 账号与安全边界](https://github.com/morenk/wenyousite-backend/blob/1776156ef8234bbc6c6cf362558773cf555e4d8f/docs/modules/admin.md#账号与安全边界)。
- 每个管理员保持单一活动会话，新登录使旧会话失效；记住设备不保留高风险操作的确认资格，邮件二次确认继续独立限制为 10 分钟。退出、身份撤销和账号不可用仍可提前终止会话。
- 初次核验和终态失效使用一致的页面状态；确认失效后统一清除管理员数据、身份及列表恢复状态，再进入登录页，避免旧后台与登录页来回闪烁。普通社区登录态保持独立。
- 网络中断、服务端暂时故障和限流提供简短错误与重试入口，不误判为退出。单个操作无权限或需要高风险确认时，在对应操作处反馈，不将其当作全部会话失效。
- 登录后的返回地址只接受已校验的站内后台页面，保留允许的筛选参数；非法或站外目标回到后台默认入口，登录页本身不构成循环返回目标。
- 切换标签页或返回后台时重新核验当前会话；跨标签页的登录、退出或身份变化先确认服务器状态，再同步当前界面，旧响应不得恢复已失效身份或覆盖新会话。核验覆盖普通和记住设备两种模式、到期与撤销、多标签页切换、临时故障重试、安全返回和高风险确认到期。
