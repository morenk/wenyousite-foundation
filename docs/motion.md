# 全项目动效与加载语义

## 范围与事实源

本规范覆盖 Web 与 Mobile 的公共组件及业务入口：加载／进度、内容揭示、页面与弹层转场、展开收起、按钮反馈、刷新分页、字体与图片就绪。统一的是状态含义、资源生命周期和验收要求；没有解释状态或空间关系的必要时，直接呈现。Apple 的平稳衔接只作为观感参考，不声称采用其内部机制。

运行时依据为正式 `v7.6.0`（提交 `1bbd5a5476b50c51d2bba1f2a218f9408a852c4a`）的 [`motion`、`experiences.feedback` 与 `experiences.overlays`](../contracts/foundation.v1.json)。数值只由机器契约拥有，本次不改变契约、Schema、生成 API、依赖版本或业务成功条件。本文与[验收用例](../tests/motion-semantics-fixtures.json)是规范和测试依据，不是新增运行时协议。

| 既有角色 | 使用方式 | 不承担的职责 |
| --- | --- | --- |
| `motion.fastMs` | 控件颜色、边框和按压等局部反馈 | 网络超时、最短等待、循环指示器一圈的周期 |
| `motion.standardMs` | 通常的内容状态衔接、展开与浮层关系 | 等待字体、图片、几何稳定或业务确认 |
| `motion.slowMs` | 确有较大空间关系需要说明的有限转场 | 给每页加进入动画、逐行排队揭示 |
| `motion.standardEase` / `motion.exitEase` | 自定义转场的常规／退出曲线 | 修改原生交互返回、手势物理或媒体时间线 |
| `motion.usage` | 沿用 `state-feedback`、`expand-collapse`、`overlay-relationship`；保留三类禁止用途与减少动态效果策略 | 新增装饰循环、列表布局跳动、持续漂浮或视差 |

必要的未知等待指示属于 `state-feedback`，不是 `ambient-loop`。只在任务真实等待且该指示器可见时播放；周期由平台指示器实现拥有，不为本轮另设全局数值。媒体动画按[图片规则](images.md)播放，不用 UI 转场时长改写帧时序。Mobile 阅读滑块的专属状态、阈值与手势仍由 `ReadingScrollSpec` 拥有。

## 任务与完成衔接

- 输入先得到按压／忙碌反馈，同一 mutation 入口立即防重；不能等动画结束才发请求，也不能凭动画完成标记业务成功。权限失效时立即撤除不再可见的内容，保留旧内容的规则不扩大访问权限。
- 分别记录业务结果、结果回填、内容可读和可选资源就绪。服务端成功只完成对应业务阶段；依业务契约回填当前数据、清理 pending，之后可继续处理不阻塞阅读的字体、图片和邻页预取。网络传输结束不自动等于校验、解码、发布或安装成功。
- 连续编辑后使用本次保存结果或该协议允许的失效／重取路径更新当前内容，不能让成功提示掩盖旧正文；结果对象、缓存键、导航锚点和任务身份一致。已有可信结果足够时不为动画重复请求正文或定位接口。
- 快速完成可直接显示结果；指示器尚未显示就取消其显示安排。已显示时及时结束，不强制最短展示、不补播一圈、不等待统一倒计时；骨架与内容占同一区域，不能先清空成白屏再揭示。
- 进入、退出、反向展开和连续任务以当前呈现值衔接，不跳回起点、不堆积动画队列。业务终态只结算一次；样式结束事件、被取消的动画或计时器都不能独立决定业务状态。
- 每轮工作绑定资源身份、账号／会话、路由与任务代次；重试新建代次。取消、替换、离页和终态后，旧进度、完成、失败及动画回调均不得覆盖当前任务、导航或播报。取消等待不表示服务端写入已经回滚；需查明结果的写操作沿用原业务确认策略。
- 失败保留上下文和必要恢复入口；安全可重复时才重试。待处理、失败和已取消不能变成无限转圈，也不能为了立即揭示而伪装成功。默认不新增常驻解释文案，保留简短状态、错误和读屏名称即可。

## 真实进度与内容揭示

已知进度只使用可信总量和已完成工作，同一任务、同一阶段内单调。重复或乱序回调不回退，平滑插值不得超过最新实际工作量；真实工作完成前不显示该阶段完成。总量变化、阶段切换或重试时明确切换阶段／任务，不能通过取最大百分比掩盖分母变化。下载完成后仍需校验的，完成只能描述下载阶段，不代表整个操作成功。

未知进度使用局部不定指示或静态忙碌状态，不用计时器编造百分比，不把长时间停在接近完成的位置当作平滑效果。混合任务只对可测阶段显示进度，其余阶段保留必要状态；不捏造整体加权百分比。

内容达到当前任务所需的最小可读条件就揭示。正文不得等待全局字体、所有图片、页面外资源或连续无变化的几何采样；字体失败仍使用系统回退，图片在自己的占位区域显示等待或失败。权限、完整性和必需业务数据仍须通过校验，不把可读降级当作授权或资源验证成功。

发布、返回和显式定位使用稳定的内容身份与本次结果。目标挂载后按当前布局定位，并为可影响目标的迟到尺寸变化安排有界校正；消费者集中定义和测试校正的次数／时间预算，不另建共享时长。用户开始滚动、切换目标、离页或达到预算时停止自动校正；目标不可用时呈现真实结果和恢复入口，不能无期限隐藏页面、重复定位或落到附近任意内容。普通内容更新保留阅读锚点、焦点、编辑选区和输入法组合态。

## 场景映射

| 场景 | 共同规则 | 平台差异 |
| --- | --- | --- |
| 首次加载 | 仅当前资源区使用结构稳定的 Skeleton；命中已有数据不重放骨架 | Web 保持主内容列／表格密度；Mobile 保持单列、文字缩放与安全区 |
| 小范围等待与提交 | 使用局部 Spinner，保留按钮标签和宽度；toggle 保留原 tone；成功前不切成成功态 | 两端复用各自共享状态组件；减少动态效果时使用静态状态 |
| 内容揭示 | 原位替换占位，必要时用现有常规尺度衔接，不逐行延迟入场 | Web 保留 DOM／数据身份；Flutter 保留 Widget key 与局部状态 |
| 页面导航 | 复用平台既有转场，保持返回关系、焦点和滚动恢复；不叠加整页装饰过渡 | Web 无需仿制 Mobile 路由推入；Flutter 保留原生返回手势及系统返回 |
| Dialog／Sheet／菜单 | 开关可中断，只有当前浮层接收交互与焦点；退出后恢复有效触发位置 | Web 键盘、焦点约束与 Escape；Mobile 安全区、系统返回及原生路由关系 |
| 展开收起 | 从当前尺寸或呈现值反向继续，不把关闭内容留在焦点／读屏顺序；必要测量有界 | 不为动画缩小触控区或裁切大字号；高度动画须测量布局成本 |
| 刷新／分页／筛选 | 保留仍有效内容和阅读位置；区分 refreshing 与 loading-more；新结果不触发全列表重播 | 各端保留自己的分页／虚拟列表策略；筛选身份变化隔离旧请求 |
| 字体／图片就绪 | 资源局部更新、复用已验证缓存与在途工作，不因普通重建重启 | Web 按 Document 与资源 lease；Mobile 按引擎注册和解码生命周期，遵循原资源协议 |

全屏图片、音频和作者选择字体继续遵守各自规范；本表不改变播放许可、撤回、缓存预算、注册上限或 Backend 的超时与重试协议。

## 动画末段与资源生命周期

持续等待指示的相位不随进度通知、列表重建或同资源的状态刷新重置。结束前后的解析、排序、diff、大批量布局和资源解码须与动画竞争一起测量；不能只通过延长动画或更换曲线掩盖主线程停顿。

Web 将无 DOM 依赖的重计算按实际成本移到 Worker 或拆成可让出主线程的工作，几何读取与写入分批组织；`requestAnimationFrame` 本身不会把重计算移出主线程。Flutter 按 trace 区分 UI／raster 成本，适合的解析交由 isolate，保留引擎／UI API 的线程约束；避免整页每帧 rebuild。两端都先定位开销，不无条件加线程、预加载或 `will-change`。

| 生命周期 | 必须保持的结果 |
| --- | --- |
| 隐藏、被覆盖、离屏或后台 | 暂停不可见的 UI 循环与帧监听；组件、路由、Tab 和应用可见性分别处理。不可见不等于业务取消，传输是否取消按资源协议执行 |
| 恢复可见 | 从最新有效状态继续，不重播旧队列，不为恢复动画重复请求、重新注册字体或增加订阅 |
| 成功、失败、取消、卸载 | 清理本轮 controller、timer、帧回调、observer、listener、临时引用；共享资源只释放自己的引用，不取消仍有使用者的工作 |
| 连续重试、往返和多资源并行 | 各任务相位与结果互不串扰；按既有缓存／注册预算复用，订阅、待执行回调和活动 controller 不随访问次数持续增长 |

“停止 ticker”不代表已取消定时器、网络或解码；“取消订阅”也不代表已释放原生内存。资源身份、撤回、有限注册及窗口预算继续依据[正文字体](thread-fonts.md)、[动态字体](thread-fonts-dynamic.md)和[图片](images.md)规则，不能为缩短等待绕过验证。

## 减少动态效果与无障碍

- 系统减少动态效果在首次渲染及运行时变化时均生效：移除非必要位移、缩放、脉冲和循环 Skeleton；以静态状态提供同样完整的信息与操作。必要等待可用静态图标／文字和忙碌语义，不依赖旋转才可理解。
- Web 对相应区域提供 `aria-busy`，进度控件有名称；未知总量不设置虚假的 `aria-valuenow`。短状态使用礼貌 live region，置于需要播报时不会被忙碌区域抑制的位置，避免每帧／每百分比重复朗读。结束、失败和取消均清除 busy。
- Flutter 以 Semantics 提供名称、真实进度或等待状态及必要 live region；装饰指示器不重复朗读。系统无障碍设置映射见 [Mobile profile](platforms/mobile.md#动效与加载接入)，不能只检查某一种动画 Widget。
- 焦点和可操作状态由真实开关／终态驱动，不依赖 `animationend`、`transitionend` 或 ticker 回调必然发生。动画被禁用、取消或组件卸载时也须完成焦点恢复和状态清理；触发器已消失时恢复到有效的上下文入口。

性能证据必须固定源码 SHA、设备／浏览器、刷新率、构建模式、样本、缓存和网络条件；标记操作开始、业务结果、数据回填、首个可读呈现与目标定位。按实际刷新率的帧预算，分别报告全过程和结果到达前后末段的长帧、最大帧耗时及分位值，并将网络等待、UI／raster／主线程工作、几何校正耗时分开。没有平台绘制证据时，rAF／回调时刻只能标记调度时点，不能当作屏幕呈现时点。对比同条件修改前后，不只报告平均 FPS、总耗时或空载 Spinner。

画面覆盖亮暗、窄屏、长内容、文字缩放、键盘／读屏及减少动态效果；Mobile 保留单列、48dp 触控、安全区并提供真实设备证据。Foundation 的静态检查不执行浏览器／Flutter，也不证明真机帧率、完整入口覆盖或负责人观感验收。真实环境自动化仅只读；保存、发布等写入测试使用已核验的独立隔离资源。

## 接入与发布顺序

1. 本轮先提交规范、共享用例和防漂移检查，交接引用其精确 Git SHA。候选未合并时标明“规范候选”；合并后可作为验收依据，但不宣称旧 Tag 内含这些新增文档。
2. Web／Mobile 继续锁定正式 `v7.6.0`，独立优化各自公共组件和实际调用点，关联本表用例并提供运行证据。规范／测试引用已提交 SHA 与运行时包依赖升级分开；不得将包依赖改到本候选 SHA 或 `main`。
3. 本轮无需新版本或 Tag。只有后续确需新增机器字段、导出或改变现有含义时，另行提交契约与生成产物，说明兼容性及版本建议，等待负责人明确合并和正式发布；之后两端用独立升级提交锁定正式 Tag。不得复制候选常量抢先接入。
4. 本轮无 API 变化，不扩 Backend。Foundation 与两端 PR 分别审查、由用户决定合并；部署和发布保持独立授权。消费者验收未完成的项随 PR 明列，不以共享检查替代。
