# 主题帖正文字体

本文规定作者选择正文字体时的共享体验。应用 UI、未指定字体的正文与平台排版尺度继续消费 [Foundation 机器契约](../contracts/foundation.v1.json)；作者选择是正文内容属性，不新增 `body`、`display`、`utility` 角色，也不修改 Foundation 的空 `fonts` 清单。

本文的目录、协议镜像与运行策略对应下述固定 Backend 快照。新增[动态字体行为规范](thread-fonts-dynamic.md)单独记录待契约接入的版本与生命周期要求，不把本文固定目录／快照预算改义为动态协议。

## 范围与事实源

- 首批当前可选目录为 28 个独立家族，名单以 Backend 目录 `1.2.0` 为准；小城拉风体退出当前可选项，历史正文身份仍保留。字重、斜体或资源分片不能重复计为不同家族。它们用于一般文字表达，不加入特效模板、动画、渐变或任意字体上传。
- 应用导航、控件、用户名、时间、计数、主题标题和列表摘要继续使用系统字体；不得把作者选择写入全局主题、整页字体或持久化为应用外观偏好。主题、子帖、楼层、回复等具体正文写入范围以 Backend 的能力与协议为准，不据共用编辑器扩大到动态或私信。
- Backend 唯一拥有字体目录、稳定 `fontId`、家族及中英覆盖、授权与来源、字重资源、Web／Mobile 文件及分片、版本／摘要、分发与能力声明，以及字体和颜色组合的 Markdown、剪贴板、摘要、错误与旧端覆盖保护。本仓不另建运行时目录或分发字体文件，不另定 HTTP API、属性语法和资源版本；测试所需目录只保留带来源哈希的原字节镜像。
- 协议与测试镜像固定 Backend 提交 `f27898ec3b168b9e027b5d5abef43a0d3dafa242`（OpenAPI `5.42.0-dev.20261022.1`）。[字体协议 v1](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/docs/markdown-text-font-v1.md)、[资源规则](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/docs/thread-font-assets.md)、[家族目录](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/contracts/thread-font-catalog-v1.json)与[资源 manifest](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/contracts/thread-font-manifest-v1.json)是本轮 28 款目录与进度超时策略来源；后续资源变更须从 Backend 新提交整体同步，不手改镜像或自造字段。消费者直接同步生产者契约，不依赖未发布的 Foundation 运行时产物。

上述固定提交登记 28 款全部 `ready` 的分片家族；`ready` 只表示资源已核验，不代表已经发布、完整字符覆盖或消费者验收通过。小城因不具备拆分／转换授权，按用户决定退出当前目录和 manifest；旧源锁、原件描述与许可记录保存在 Backend [退役审计](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/contracts/archive/thread-font-xiaocheng-lafeng-v1.json)，旧不可变包保留。

正文 v1 Schema 仍识别包含小城在内的 29 个历史身份，不能用当前目录重写历史身份白名单。小城历史范围可保留、重排或移除，新增／扩展范围返回 `TEXT_FONT_DISABLED`（409／40020），旧端覆盖保护不变；客户端保留历史文字和标记，以系统字体显示，不下载或用旧缓存恢复可选项。当前选择与新写权限由目录及能力共同决定，不能把解析成功当成允许新选，也不能通过复制粘贴绕过新增／扩展禁令。

## 语言分组

选择器按主要设计语言提供中文、日文、英文分组，两端直接消费 Backend 目录、meta 与 manifest 的 `designLanguage`（`zh`／`ja`／`en`），本快照分别为 12／10／6 款，不按研究别名、展示名称或字符覆盖自行推断。侵食明朝、白光明朝、冒险黑体和怪盗予告黑体按本轮选择要求归日文；包含汉字不能据此改归中文。旧后端缺少该字段或未来返回未知值时保留未分类／系统回退，不能猜测语言；Foundation 不建立独立 ID 到语言的映射表。

分组用于选择，不承诺该家族覆盖整种语言或所有字符；中英日混排仍逐字符回退，保留作者文字和 `fontId`。分组切换、当前 28 款目录和最近使用都不触发全组或全目录预载，既有进程预算继续生效。验收核对两端同源分组、真实样字、缺字回退和切组请求量，不能把语言标签当作完整覆盖证据。

## 协议接入与共享验证

字体使用独立 v1 协议，与颜色共用受控 `span`；字体属性在前、颜色在后，接受逆序输入并规范化。字体与颜色之外不扩展 HTML／CSS 白名单，不允许嵌套、空区间或跨物理行 span；粗斜删、普通链接与行内代码在内，块前缀在外，跨原子选区拆开。去掉最后一个属性时按完整内联语义重序列化，不能简单删标签而激活字面 Markdown 或破坏相邻 marks。精确语法和规范输出以源协议与语料为准。

读取分别声明 `X-Text-Font-Version: 1` 和颜色读取能力；支持新协议的客户端在所有正文写入 DTO 始终声明 `textFontVersion: 1`，包括删除全部字体的保存，不能以请求头代替 DTO。组合颜色需同时声明 `textColorVersion: 1`；正文创建、编辑、BODY upsert、聚合保存和云草稿各入口都需覆盖。字体与颜色四种读取组合如下：

| 字体能力 | 颜色能力 | 组合内容的读取结果 |
| --- | --- | --- |
| 有 | 有 | 保留字体与颜色 |
| 有 | 无 | 只保留字体 |
| 无 | 有 | 只保留颜色 |
| 无 | 无 | 安全 Markdown 原文与其余 marks |

新写默认关闭；后端能力缺失按 false，不显示可创建字体的入口。关闭新写时可保留、重排或移除已有范围、编辑无字体文本；不能新增、改字体或改已有字体范围内的文字与 marks。颜色变化单独受颜色门控。缺 DTO 能力、禁用新写及非法字体分别由 Backend 的 `TEXT_FONT_CAPABILITY_REQUIRED`、`TEXT_FONT_DISABLED`、`INVALID_TEXT_FONT` 拒绝；客户端保留输入并就地反馈，不能静默降级重试覆盖。完成所有保存入口和保源路径后再声明能力。

`GET /meta/text-fonts` 返回目录、状态、manifest 描述符和 `assetBaseUrl`。base 为 `null` 时不请求字体、manifest 或上游来源；只有自有发布地址、相应能力和可用状态满足时才加载。新写还须满足独立新写开关，不能把 `ready` 或资源可下载当成允许写入。缓存按后端 `Vary` 保留字体／颜色／角色提及能力区分，不能把去样式副本覆盖原始内容。

## 内容与编辑

- 同一 `fontId` 在 Web 和 Flutter 指向同一家族；原文、中英文、标点、空格、换行和 emoji 保留。两端不以本机字体名、展示名、数组位置或下载 URL 代替持久化身份，也不因平台资源不同存成另一个字体。
- 字体与文字颜色、粗体、斜体、删除线等属性分别修改；换字体或恢复“默认”只改变字体属性，不能清除颜色和其他格式。字体、颜色与普通链接、行内代码、标题、列表、引用的合法组合、优先级和序列化均以 Backend 固定语料为准，不由 CSS 继承或第三方解析器偶然决定。原子节点保持自己的身份与呈现。
- 有效文字选区只修改适用文本；跨段按协议支持的行内范围处理，混合字体不误报为某个单一家族。打开选择器、滚动或预览不改原文；应用一次形成一次可撤销格式事务，取消恢复原选择与焦点。无效选区和仅含不可格式化节点的选区不产生空标记。
- 有效折叠光标允许先选字体后输入；选择本身不改文档、草稿或撤销栈。连续输入、中文输入法组合与换行保持显式输入字体，主动移动光标或重开文档后按新位置恢复；默认只清除输入字体，保留颜色等状态。富文本粘贴按来源保留合法格式，不用当前输入字体覆盖粘贴内容或原子节点；未输入的临时状态不写入草稿。
- 编辑态、选择器样字预览与阅读态使用相同的家族解析、可用字重和缺字回退。首批每家族只有一个默认字款，OFL 派生 face 的基础字重／样式以 manifest 为准；粗斜体仍是独立 marks，两端使用一致合成策略并实测效果，不把不同字重计为新家族。使用现有字号、行高、段落层级和系统文字缩放；不能为了某个家族缩小字号、强制字宽或裁掉高字形。平台字形栅格化和换行允许差异，不承诺像素相同。
- 草稿、重开、受支持的站内结构化剪贴板和跨端文档编辑往返保留合法字体及颜色组合；剪贴板载体及粘贴目标的限制见下节。纯文本复制、摘要和读屏保持可读原文，不泄漏协议标记。资源未到达不能成为丢弃字体属性的理由；解析或转换无法保源时阻止覆盖保存，保留编辑现场并给出可恢复的错误。

## 摘要与剪贴板

自定义字体仅作用于主题帖正文的阅读和编辑。主题、动态、消息列表，以及搜索、通知和分享预览中的摘要全部使用默认系统字体；即使复用正文解析器或已有字体缓存，也不应用自定义 face，不触发自定义字库下载、注册或预热。摘要按既有纯文本投影去掉字体和颜色，不显示协议标记；投影只作用于展示副本，不能写回或修改源正文的 `fontId`。

剪贴板继续遵循固定 Backend 提交的[字体协议](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/docs/markdown-text-font-v1.md)及[剪贴板 v2](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/contracts/editor-clipboard-v2-fixtures.json)，先验证载体和受控属性，再按目标能力转换：

| 来源与粘贴目标 | 字体与内容处理 |
| --- | --- |
| 合法站内结构化内容 → 支持字体的主题正文编辑器 | 保留目录支持的 `fontId` 与目标支持的颜色、粗斜删、链接等格式；字体暂未加载不丢失身份，写入仍遵守能力与新写门控。 |
| 含退役小城字体的合法结构化片段 → 主题正文编辑器 | 在粘贴片段入口移除 `xiaocheng-lafeng` 字体属性，保留可见文字及目标支持的颜色、粗体、链接等格式；混合片段中仍获准使用的字体保留，不把退役身份插入新内容后等提交拒绝。 |
| 合法站内结构化内容 → 动态等不支持字体的编辑器 | 移除字体标记，保留文字和目标支持的其他格式；不能因去字体一并清空合法格式，也不借粘贴开启目标不支持的颜色或节点能力。 |
| 纯文本粘贴 | 以默认字体插入可见文字，不从当前输入字体、剪贴板旁路数据或形似协议的字面文本恢复字体。 |
| 未知 `fontId`、未知／无效 envelope 或属性 | 按既有无效载体规则回退可见文字和默认字体，不把未知 ID 引入新内容。 |
| 外部 HTML／CSS 字体 | 沿用外部内容的字面文字策略，使用默认字体；不映射 `font-family`，不接受任意样式或引入字体 URL。 |

上述去字体只针对摘要副本或本次粘贴插入的内容，不清理来源文档或已有历史正文。已有正文中的未知或暂不可用 `fontId` 仍保源回退，不能把粘贴入口的过滤规则套用到保存重开。去掉最后一个属性时仍按完整内联语义重序列化，保留可见文字、其他合法 marks 和字面 Markdown。

退役字体过滤仅处理本次粘贴片段，不放入共用正文解码或编辑回填流程；原帖历史小城范围仍保源。验收覆盖复制历史小城到新主题、粘贴到已有主题及与当前字体混合的片段，确认只去退役字体且文字／颜色／粗体／链接保留；动态等不支持字体的目标仍移除全部字体。

Web 使用既有严格白名单 envelope。Mobile 只在本机进程内结构化载体通过文字、随机标记、会话和有效期核验后恢复格式；系统选区复制和跨应用／跨设备系统剪贴板继续使用可见纯文本，不承诺通过它们保留字体。本文澄清既有作用域，不修改剪贴板 v2 或共享固定语料。

## 选择器与加载

- 复用现有正文样式入口和平台控件，不新增常驻主工具栏按钮；显示字体名称、默认、选中态及必要加载／失败状态。名称始终使用 UI 系统字体，样字体现其主要设计语言，并覆盖中英日混排回退；不为每个家族添加说明段落、营销文案或装饰卡片。
- 预览使用 Backend 提供的轻量资源或当前单项按需样字；不可为了展示首批 28 个家族的目录先下载全部完整正文字体。未有真实样字时保留名称与加载状态，不能把系统回退伪装成该家族的实际效果。
- 最近使用只记录已确认使用的 `fontId`，按账号保存在本机、去重并保持有限条目；悬停、滚动和失败预览不计入，不跨账号泄漏。最近使用列表本身不触发字体下载或后台预热，条目失效不改历史正文。
- 正文只为当前需要展示或编辑的文本加载相应家族和资源；新进入视口的内容再按需处理。请求去重、有界并发，可复用已校验缓存；快速切换、关闭面板与离开页面时停止无用工作，迟到响应不得覆盖新选择。不在启动、登录、打开选择器时批量下载所有家族。
- 未知字体、字体未到达、断网、下载失败、哈希不匹配、缓存被回收、缺字或超过预算时立即以系统回退显示原文，保留请求的 `fontId`。缺少某个字符时按字符回退，不能用空白、方框占位或替换文字冒充支持；验收中文生僻字、中英标点和 emoji。下载失败不阻断阅读和保源编辑。协商新运行策略后，临时错误按资源退避，联网恢复、回到前台、仍有效的可见需求及到期调度静默唤醒；窗口受限时等待下一次获准机会，不以累计家族数永久阻断后续阅读，不要求刷新、重启或新增操作入口。完整性、解码、不可信及撤回状态单独隔离，不套用临时错误重试。
- 字体到达会改变字宽和换行，须保持当前可见文字锚点及其视口位置、光标、选区和输入法状态，并更新长列表测量；不能跳回顶部、跳到另一楼层或反复闪烁。不可安全替换时延后该次显示切换并保持可读回退，不以锁死高度、截断或隐藏正文维持假稳定。

## 平台资源与成本

Web 与 Mobile 使用同一业务身份，但消费各自的资源描述，不要求相同文件或加载机制。具体差异见 [Web profile](platforms/web.md#主题帖正文字体) 和 [Flutter profile](platforms/mobile.md#主题帖正文字体)。旧 manifest 的顶层、`limits` 及累计含义保持不变。持续加载通过独立、显式协商且绑定 manifest SHA-256 的运行策略启用；接口、协商方式、优先级、范围及新旧端回退以 Backend 已提交契约为准。不能向旧 manifest 插入未知字段，或仅替换旧字段名称便宣称启用窗口预算。运营分发预算与客户端预算分开执行，本仓不另建数值表；交付需报告配置与实测，不能仅写“按需”或“有缓存”。

当前 28 款均使用 `deliveryMode: subset`，Web／Mobile 按同一字符分片身份消费各自的 WOFF2／SFNT。小城的项目使用授权不扩大为拆分或格式转换权利，当前选择器、发布对象集合和 v2 运行策略均不再提供其原件或额外预算槽。`originalAsset`、`network.originalWindowBytes` 与 `web.residency.originalSfntBytes` 不属于当前 v2 形状，不能从旧策略拼接回来。

旧 v1 Schema、历史 `original` 模式和绑定原件的 `budgetException` 保留兼容，旧 manifest 的 `additionalSessionBytes` 仍为原累计含义；这些历史规则不是当前目录外资源的加载许可。旧哈希路径和审计记录不覆盖、不清理，也不删除已保存正文的字体标记。

假名不在固定 `core` 中；按正文实际字符和 `unicodeRanges` 加载额外分片，不能把 core 缺假名误判为整个家族缺字。覆盖仍以完整家族为准：敬峰中山王篆缺拉丁字母，Hachi Maru Pop 缺 `ゕ`／`ゖ`，英文分组不承诺中文覆盖。实际样字需区分原生字形、额外分片与系统回退。

资源加载先验证 manifest 描述符，首次使用家族时同时取得并校验完整许可与归属，随离线缓存保留；字体通过实际长度和完整 SHA-256 校验后才缓存或注册。只复用已验证且仍获准使用的缓存。旧端仍按旧策略执行；新端按运行策略区分临时故障、缓存损坏、网络返回的完整性失败、解码失败和撤回，不把所有错误永久记为会话失败。坏缓存不得注册；重新获取次数、隔离解除及元数据刷新条件以生产者契约为准。恢复网络不清除完整性／解码隔离或撤回状态，缓存命中也不能绕过撤回。预览、许可和归属请求按新旧策略各自的口径记账。派生资源展示名直接使用目录的 `name`，不以来源名称覆盖它；原始字体名用于归属，避免将 RFN 当作派生主名称。

## 持续加载与资源生命周期

运行策略固定 Backend `f27898ec3b168b9e027b5d5abef43a0d3dafa242`（API `5.42.0-dev.20261022.1`）的[协议说明](https://github.com/morenk/wenyousite-backend/blob/f27898ec3b168b9e027b5d5abef43a0d3dafa242/docs/thread-font-runtime-policy.md)、[策略 JSON](../tests/fixtures/text-font/thread-font-runtime-policy-v2.json)、[Schema](../tests/fixtures/text-font/thread-font-runtime-policy-v2.schema.json)和[固定用例](../tests/fixtures/text-font/thread-font-runtime-policy-v2-fixtures.json)。独立公开入口 `GET /api/v1/meta/text-fonts/runtime-policy` 返回标准 envelope，成功缓存按生产者约定；`policyVersion: 2` 必须同时通过 Schema、模式和 manifest 绑定校验。

先验证目录描述符、manifest 的字节／SHA／Schema，再验证运行策略，`manifestSha256` 须同时匹配描述符与实际文件。404、未知版本／模式、无策略或绑定不符均不启用 v2，可使用已验证的 v1 限额读取，不能获得无限额度；错配仅按正常元数据刷新重取，不跨 manifest 拼装。当前目录与 manifest 升为 `1.2.0`，策略只绑定新 manifest SHA；旧不可变 manifest 路径保留，`limits` 与历史小城 `additionalSessionBytes` 的累计含义保持不变。不得把新描述符写到旧哈希路径，或用历史 manifest 的哈希验证当前策略。

目录与策略请求从首次发现起就共用平台网络账本，不能只约束字库文件。每次无资产描述符的元数据请求在发出前按本地固定 **64 KiB** 响应上限预占，并在读取响应流时执行上限；不能相信 Content-Length 或响应字段来放宽。约 5 MiB 的 manifest 按已验证资产描述符单独计费，不套用元数据读取上限。manifest、许可、归属、字体、失败、取消、重试及网络缓存重验证均计请求；纯本地已验证缓存命中不计网络窗口。

窗口以单调时钟记录实际请求开始时的完整描述符字节预留，元数据使用上述固定预留；预占与并发准入原子执行。事件年龄达到 `windowMs` 才过期，不按墙钟整点清零。失败不立即退款，额度按时间自然恢复；请求或字节不足的可见需求在最早过期时间重新调度。已知离线暂停请求，不扣请求或失败计数；无使用者的历史需求退出队列。

网络窗口、磁盘缓存、下载／解码缓冲及引擎注册资源分别记账。窗口到期只恢复相应网络额度；磁盘 LRU 淘汰只释放文件；两个事件均不代表引擎字体已卸载。运行策略不替代资源可用状态、新写开关、正文范围或 clipboard v2；未发布地址和不可信描述符不得因持续加载而获得请求许可。

Web 在同一 `Document.fonts` 注册域共用运行时和账本，以当前可见阅读及编辑需求持有资源 lease，多个组件／路由共享同一资源，不各建独立额度；不同 Document 不声称共用浏览器级 RSS 上限。仅无引用资源可进入 LRU 回收，移除手动注册的 FontFace 并清理应用持有；资源再次需要时可从已验证缓存或获准下载恢复。应用实际解除相应注册与二进制、已完成 Promise、family 列表及保护集合的持有后，才归还驻留额度；删除集合项不证明浏览器已即时归还内存，必须报告重复阅读后的实际内存走势。过期请求和迟到结果不得恢复旧 lease、旧目录授权或覆盖当前选区。普通片下载前按已验证的 `shard.mobile.bytes` 预占 SFNT 估算额度；WOFF2 通过 SHA、长度及 MIME 校验后读取 `totalSfntSize`，解码／注册前按两者较大值补足预留。不得把压缩下载长度当作驻留成本，也不要求这两个估算值相等；正在解码／注册的资源也计入账本。当前全部分片共用普通驻留额度，不再提供原件额外槽；同 SHA 的在途请求与驻留引用继续合并。瞬时驻留不足等待 lease 释放后自动续载；网络失败且尚未注册时解除待注册持有，完整性或解码失败则隔离。

Mobile 固定本轮已核验的有限注册快照，按需注册，每个 hash＋family 在同一 FlutterEngine 内最多进行一次原生尝试，在调用引擎前预占并登记尝试；成功后复用，原生失败也隔离并继续记账。尝试及已注册记录不随路由、窗口或磁盘缓存淘汰而删除。目录或策略刷新不得把新版本资产无限并入快照，同哈希也不得通过生成新 family 绕过去重。每个 FlutterEngine 首次接受策略后固定快照，超出集合或新的未验证快照不能扩充当前引擎，既有集合继续渐进加载；不能自行重启引擎或将原生注册描述为 LRU 卸载。按唯一资产及 `(SHA, family)` 两套口径重新汇总数量和输入字节，均须满足消费者本地固定的 1,024 项／256 MiB 接受边界，远端放大字段也不授权放宽。同 SHA 多 family 的每次原生注册分别计成本。下载失败且尚未调用原生不占注册次数；调用后的失败保留占用并隔离，成功后释放不再需要的 Dart 字节及已完成 Future。整个快照的输入字节总量是有限输入上界，不是 RSS 上限，也不是启动时全量加载的许可。

新策略下的调度应合并重复需求，保持有界并发及队列，优先处理仍可见／正在编辑的内容；离开视口且无使用者的任务停止无用工作。按资产 SHA 合并网络请求及连续暂时失败计数，只有网络错误、超时及 `retryableHttpStatuses` 声明的状态可重试；成功清零计数。第 n 次失败使用策略对应的退避上限，full jitter 为 `floor(U × (ceiling + 1))`（`0 <= U < 1`）。下一次尝试取退避、窗口可用时间和有效 Retry-After 的最晚值；非负秒数和 HTTP 日期均受支持，日期以响应到达时墙钟换算非负等待后转换为单调截止时间，非法值忽略、过期日期不增加等待，不能用退避上限截短服务器等待；联网与前台事件只触发重新评估，不能绕过服务器等待时间、窗口额度或隔离，不同时放行所有失败资源；等待额度的可见需求能在允许时继续，不新增重试按钮、提示条或要求用户刷新。Schema、身份、SHA、长度、MIME、解码及撤回／不可用状态不进入暂时重试，仅新的已验证描述符或明确修复流程可重评估；已发起 Mobile 原生调用的键仍受引擎期一次约束。缺字按覆盖信息回退，不为不存在的字形循环下载。

### 进度超时与取消

当前 Web／Mobile `network` 均要求 `timeoutMode: idle-with-total-cap`、`timeoutMs: 15000`、`maxTransferMs: 600000`。旧 v1 manifest 的 `downloadTimeoutMs: 15000` 仍表示总超时；缺少新字段或不识别模式的消费者按发现规则回退旧策略，不能仅凭相同数字猜测新含义。

实际发出请求时，用单调时钟同时启动 idle 与总传输计时，排队、额度等待和退避不计入传输时长。首响应等待包含在最初的 15 秒内，响应头不重置 idle；只有通过本次流式限长检查的非空正文块才把 idle 截止更新为当前时刻加 15 秒。空块、重渲染和窗口续额均不算进度。连续有进度的普通分片可超过 15 秒完成，总截止仍固定为请求开始加 600,000 毫秒。

每次读取／完成回调先检查两个截止，达到任一截止即中止底层请求及 reader，丢弃未核验部分并按暂时超时退避；迟到的数据块或 EOF 不能因定时器尚未执行而被接受。恰好位于截止也算超时，两个截止相同时总时限优先。响应体结束后清理计时器，再执行完整长度、SHA、MIME 和解码校验；传输 `complete` 不等于可注册或已显示。

全部共享需求离屏或应用进入后台时取消传输；单个组件离屏而仍有可见 lease 时保留共享请求。需求取消不增加网络失败计数，重新可见／回到前台后仍服从已有窗口、退避和 Retry-After；撤回／不可用保持隔离，不自动重排。开始过的请求及字节预留不立即退款，取消确认后才释放并发槽；窗口先过期也不能提前释放仍在下载的并发或另开同 SHA 请求。临时持有按实际结束清理，不清零驻留或 Mobile 原生尝试账本。

上述计时覆盖字体、manifest、许可／归属及元数据，64 KiB 元数据流式上限及资产长度限制不变。HTTP 状态在首响应时分类，错误响应的正文进度不延缓拒绝；304 只能复用已验证缓存。未读完便断开属暂时网络失败，完整长度／SHA／MIME／解码错误仍隔离，不因有进度而无限重试。

小城原件在旧 29 款方案中的慢链路反复超时是发现记录；当前验收使用 28 款中的普通分片。旧 29 款 Android 实验和 869 资产／203,056,088 字节快照只作历史上界，不改名为新 28 款结果。当前 868 资产／注册键及 184,645,488 字节是输入账本，不是 RSS 验收。
