# 主题帖文字颜色

机器事实源为 `contracts/foundation.v1.json` 的 `experiences.editor.textColor` 与 `experiences.elements.inline.textColor`。Web 消费 `@wenyousite/foundation/editor` 的 `EDITOR_TEXT_COLOR_PROFILE`、`EDITOR_TEXT_COLOR_PRESETS`，Flutter 消费 `WenyouEditorTextColorContract`；本文不另外定义预设数值或业务 DTO。

## 适用范围与呈现

主题正文、子帖正文、楼层和回复共享文字颜色；动态、私信和主题标题不开放。颜色为不透明 RGB，作者指定的原值在阅读态、编辑态、明暗主题、草稿和富文本剪贴板中一致保留，不自动调整，不提示对比度不足。该规则只适用于作者正文，应用控件和默认正文继续遵守现有主题与对比度规则。

显式文字色优先于普通链接和行内代码的默认前景色，链接下划线、行内代码背景、字号、字重及其他格式保留。恢复“默认”只移除颜色标记，重新继承各元素自己的前景色。图片、骰子、提及、传送门等原子节点不着色；不能让外层颜色继承覆盖它们的既有视觉与身份语义。

## 共享编辑语义与 App 交互

- 主工具栏不增加独立按钮。“正文样式 T”内展示默认、机器契约中的五个预设、最多四个最近自定义色与“自定义”。最近色只记录已应用的自定义 RGB，按账号保存在本机，规范化去重并按最近使用排序。
- 有效文字选区只修改所选范围；跨段拆成各行内区间，跳过原子节点，混合颜色不误选某个色块。范围改色不主动建立后续输入色。只有原子节点的范围和无效光标禁用颜色操作；原子前后的有效折叠光标仍可插入普通文字。
- 有效折叠光标（含空正文）允许先选色，再输入彩色文字；点“默认”只清除后续输入色，保留其他输入格式。选色本身不修改文档、不把草稿标为已修改，也不制造空撤销记录；实际输入沿用编辑器正常撤销／重做。
- 显式输入色随连续输入、输入法组合输入和换行保留；换行字符本身不承载行内颜色，下一行新文字继续使用输入色。主动移动光标、改变选区或替换文档后按新位置样式重新计算。取色面板自身的焦点切换和原光标恢复不算主动移动。未输入的临时颜色不写入草稿；重开编辑器按文档与恢复位置决定格式。
- 富文本粘贴保留源格式，插入原子节点不染色；随后继续手工输入仍使用本次显式选择的输入色。输入状态须区分未显式选择、显式 RGB、显式默认色，避免“默认”操作被光标处原有颜色覆盖。
- 默认、预设与最近色点选即应用并收起；打开“自定义”时保存正文光标或选区并收起正文键盘，在同一工具区域替换为拖动取色、R/G/B 整数输入和文字预览，不叠加独立弹窗。
- 调色只更新面板预览，“应用”在文字选区提交一次格式事务，在折叠光标设置输入色；取消保留原文和进入面板前的输入色。范围改色一次撤销还原整次变更；应用或取消后恢复正文焦点和原光标／选区。数字输入使用数字键盘，取色区按可用高度滚动，适应半屏编辑器。
- 控件满足移动端最小触控尺寸；色块提供可读名称与选中语义，拖动取色同时提供可访问的 RGB 输入。保留必要字段标签、错误与恢复操作，不增加常驻说明、成功弹窗或对比度告警。

## Web 交互与协议边界

Web 在现有“正文”菜单内提供颜色，不增加主工具栏按钮。第一行排列默认 T 图标、五个预设和“自定义”；默认色只显示图标，保留“默认”的可访问名称。最近自定义色存在时才出现单独一行，继续按账号保存在本机，最多四个、规范化去重、最近使用在前。菜单保持 Web 信息密度，沿用平台控件尺寸，不强加 App 的 48dp。

“自定义”替换同一 popover 的内容，提供拖动取色、R/G/B 整数输入和文字预览；不叠加弹窗、不提供透明度或常驻说明。字段仅接受 0–255 整数，缺失或无效值不提交。颜色控件提供名称、选中状态和可见键盘焦点，Tab 可以到达数值和动作控件，Escape 按取消处理。菜单锚定原正文按钮，随可用宽高适配；预览与编辑区域都不溢出窄屏或浏览器缩放后的视口。

有效选区与折叠光标共用上述 `selection`／`caret` 规则，空正文也可以先选色后输入。打开菜单前保存正文光标／选区与临时输入色；默认、预设、最近色即点即应用并收起，RGB 调整只影响预览，应用才提交一次范围格式事务或设置输入色。取消或关闭取色保留原文及进入面板前的输入色，应用／取消恢复正文焦点与原选区；菜单内部焦点切换不重置输入色。主动移位、中文输入法、换行、撤销、粘贴与原子插入仍遵循共享语义。

Milkdown 解析、编辑事务与序列化不能丢失颜色；正文往返检查必须比较颜色，转换失败阻止保存并保留编辑现场。入口仅在适用正文且后端声明支持并允许新写时开放；新写关闭时仍读取与编辑保源，服务端既有覆盖保护继续生效。Web 的外部剪贴板行为保持原有策略，不将本次取色入口扩展为接受任意 HTML/CSS。

正文协议、受控标记、能力声明、旧端读取降级、缓存区分和旧端覆盖保护由 Backend 的独立文本颜色 v1 契约拥有。只接受其受控 `span`，不因此开放任意 HTML、CSS 或未知属性；颜色外层与粗斜删、普通链接及行内代码的组合、物理行范围和原子排除以固定后端语料为准。不提升全局 Markdown 版本，不替代角色提及能力。合法协议的纯文本复制与摘要只保留文字，不泄漏隐藏标记。

## 已提交协议来源

[Backend 文本颜色 v1](https://github.com/morenk/wenyousite-backend/blob/7f58f9c15269663a9e615493c82e2084afd300c8/docs/markdown-text-color-v1.md)拥有精确协议；[固定颜色语料](../contracts/fixtures/markdown-text-color-v1-fixtures.json)、[节点 Schema](../contracts/fixtures/markdown-text-color-v1.schema.json)与[剪贴板 v2](../contracts/fixtures/editor-clipboard-v2-fixtures.json)按该提交原字节同步，来源及 SHA-256 记录于 [text-color-source.json](../contracts/fixtures/text-color-source.json)。

合法颜色只包裹单个物理行内的平衡格式；H2/H3、引用和列表前缀位于颜色外。旧端去色须按整段行内语义重序列化，保留边缘空白、格式邻接和可能变成块语法的字面标点，不能简单删除标签再解释。关闭新写时，完整连续同色范围按文字与格式语义多重集比较；等价转义、分隔符和相邻同色分片不算新增，真实改字、改色、改格式与增加范围次数仍拒绝。Mobile 本机结构化剪贴板保色，系统剪贴板继续纯文本互操作；Web 只识别本站 envelope 的受控颜色属性，外部 HTML/CSS 仍按既有纯文本策略处理。

此镜像不定义 HTTP Schema，也不代表后端已合并或部署；消费者应在服务端能力确认后开放入口，新写关闭仍需读取保源和旧端覆盖保护。

## 验收与发布

共享检查覆盖 Schema 反向用例、预设和导出同源、现有主栏不扩张、Web 二级创建入口与紧凑行布局、原值呈现及原子排除。消费者另验选区、取消、默认、单步撤销／重做、RGB 边界、混合颜色、跨段、中文输入法、emoji、组合格式、草稿和 App → Web → App 往返，不能将 Foundation 常量检查代替实际编辑与视觉验收。

折叠光标新增验收：空正文和已有文字间先选色后输入；取消取色保留原输入色；默认色保留粗斜等格式；输入前不改变正文和撤销栈；连续中文组合输入、emoji 与换行保持显式色；主动换位置或范围改色不遗留临时色；粘贴富文保留源格式、原子不染色；撤销输入、重做与草稿重开正确保留实际文字颜色，不恢复未输入状态。

App 视觉候选须提供 320/360dp、明暗、大字号和键盘状态画面；Web 候选须提供桌面与窄屏、明暗、浏览器缩放和键盘操作画面；自动化真实环境只读，写入 E2E 使用本轮核验的隔离资源并记录清理结果。

首期选区改色已获负责人明确批准，以 `7.4.0` 升版、合并和发布正式 Tag／Release；根包、Flutter 包、契约及 Manifest 同步版本。发布前重新生成并通过完整检查；消费者只能在正式发布后独立锁定 Tag，不消费候选提交或复制常量绕过发布。发布顺序为兼容后端 → 可读保源消费者 → 开启新写。回退消费者不删除存储中的颜色；旧端兼容和覆盖保护继续保留，后续清理另开 PR。
