# 长讨论编号定位

本规范描述主题子贴主楼及独立楼中楼的共享阅读体验。HTTP 字段、编号分配、权限与分页由 Backend 已提交契约拥有；消费端使用治理交付的精确提交，不从本规范复制 Schema。

## 编号与入口

- 主楼沿用本子贴既有楼层号；楼中楼使用本根楼下的固定回复编号。统一显示 `#N`，排序、作者筛选、新增或删除其他内容不改变已有编号，删除可以留下空号。
- 编号用于定位身份，不等于当前可见条数或筛选结果排名。总数、最大可访问编号和可见性均来自 Backend，不能用列表索引补造编号或从缺号推断隐藏内容。
- 现有楼层／回复统计可打开定位；统计行滚离后，在现有吸顶阅读区域保留紧凑位置按钮，显示阅读区域上方正在阅读的条目编号。无正文编号的子贴正文区域只显示定位动作，不伪造当前楼层。
- 位置按钮复用普通控件圆角与主题，不新增品牌徽标或全宽工具栏；Mobile 保持至少 48dp 有效触控区域。复杂顶栏优先收缩标题，不挤掉返回和必要操作。

## 简洁定位面板

- 仅包含“跳转到楼层／回复”标题、单行“当前 #N · 编号至 #M”辅助信息、带可访问标签的编号输入，以及“前往”动作。初次尚无当前编号时省略该部分，空讨论不开放无效定位。
- 不提供“最早／中间／最新”按钮、百分比轨道、分页页码或解释内部加载方式的文案。Mobile 和窄屏 Web 使用现有底部 Sheet；桌面 Web 采用紧凑浮层，保持本平台的信息密度。
- 打开时不自动唤起软键盘。输入使用数字键盘，键盘提交与按钮行为相同；非正整数、空值或超出服务端已知可访问上限在原处反馈，失败保留输入。编号不存在或已不可访问不静默跳到另一条。
- 精确目标被作者筛选排除时，沿用明确提示后恢复全部作者再定位的行为；仅专用业务结果触发该恢复，其他错误不能被当作筛选冲突。
- 关闭恢复触发入口焦点，等待时保留取消／返回能力，读屏只在成功或错误时播报，不逐次朗读滚动位置变化。

## 跳转与连续阅读

- 编号输入与搜索、通知、图片来源、复制链接的帖子 ID 入口使用同一定位流程。直接读取目标附近，不能从第一页逐页扫描才能抵达。
- 对齐目标作者及正文开头，复用既有短暂目标描边与加载过渡；不演示穿过上千楼的滚动动画，不以全量图片加载完成作为可阅读前提。减少动态效果时直接呈现。
- 在同一阅读会话内提供按需“回到刚才”，以目标 ID、条目内偏移及讨论／排序／筛选上下文恢复；不是跨设备或跨启动的持久阅读进度。离开讨论、账号变化或权限失效清理恢复状态。
- 正常进入主楼列表仍优先展示服务端提供的有界置顶区，并按 ID 避免自然序列重复。直接跳转、深链及位置恢复重建目标窗口，置顶内容在自然编号位置呈现一次，编号和置顶权限均不变化。
- 向前与向后均可继续自动分页；前插、裁剪远端窗口和图片尺寸变化保持阅读锚点。用户主动滚动后停止原目标吸附，不能把用户拉回。

## 性能与既有交互

- 数据只预取阅读位置附近的少量页，缓存具有明确上限。变高正文只构建视口附近及有限预布局区域；远处内容可释放，不以全量预取或永久保活掩盖远距离定位成本。
- 图片沿用可见邻域加载和尺寸占位；正文编辑、版本变化和主题／字号变化按原规则失效缓存，不能显示陈旧正文。被编辑或正在选字的条目在当前操作结束前保持可用。
- 既有回复、编辑、删除、置顶、举报、选字、作者主页、链接、图片和草稿交互保持。移动端现有阅读滑块继续表示已加载范围及附近快滑，不将它解释为完整讨论的精确全局进度。
- 框架、窗口大小和缓存实现由各端负责；共享语义复用已发布 Foundation Token、组件和无障碍规则。本次不修改机器契约、生成物、包版本或发布 Tag。

## 验收

覆盖 1,000／5,000／10,000 条、长短正文与图片混排、正倒序、作者筛选、置顶、编号空洞、不可访问目标、取消与乱序返回。检查目标请求次数、活动渲染数量和缓存上限，而非只看最终列表能否出现。连续往返和前后分页核对无遗漏、重复和可见跳动。

两端提供明暗、320px／dp 窄屏及两倍文字缩放的实际画面，移动端区分 Widget／Golden 与真机证据；读屏、键盘、软键盘和减少动画均需覆盖。真人体验使用身份核验通过的隔离预览，合成压力数据与当天真实快照分别登记。自动检查不代表负责人已完成体验验收。
