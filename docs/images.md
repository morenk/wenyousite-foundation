# 跨端图片呈现契约

## 边界

本契约规定用户在 Web 与 Flutter 看到同一种图片时应获得的共同语义，不规定上传接口、对象存储 key、派生图命名或业务页面的固定像素。媒体 URL、尺寸、处理状态和可用派生版本由后端生产者契约提供；客户端只能消费显式字段，不自行拼接或猜测 URL。

## 内容角色

| 角色 | 默认适配 | 是否允许裁切 | 查看完整来源 |
| --- | --- | --- | --- |
| 头像 | cover、圆形 | 允许 | 不要求 |
| 封面 | cover、圆角 | 允许 | 可交互时必须 |
| 正文图片 | contain、圆角 | 禁止 | 必须 |
| 画廊缩略图 | cover、圆角 | 允许 | 必须 |
| 收藏表情 | contain、内容形状 | 禁止 | 按场景可选 |

裁切只属于明确的预览语境。用户进入大图查看后必须回到完整来源，不能继续沿用封面或缩略图的裁切框；正文中的长图、截图和含文字图片不得为了列表整齐丢失信息。

## 布局与状态

- 服务端提供宽高时，在图片请求前按真实比例预留空间；未知尺寸使用角色占位而非任意猜测原图比例。
- 加载、处理中、失败、受限和敏感内容都保留原有上下文、比例和可执行下一步。状态由图标/文字/操作共同表达，不只改变颜色。
- 图片失败不能让标题、说明或消息正文一起消失。可安全重试时提供重试；无权限或敏感内容要求确认时提供明确揭示操作。
- 头像可降级为统一占位；正文图和附件不能伪装成头像式字母圆点。
- 动图不影响布局尺寸；进入可见区域前不抢占带宽。减少动态效果下不得把播放作为理解内容的唯一方式。

## 可访问性

- 有内容意义的图片使用所在上下文生成的简短替代文本，不使用文件名、对象 key 或“图片”作为唯一名称。
- 纯装饰图使用空替代文本并退出读屏顺序；可点击图片的查看动作必须有独立可访问名称。
- 不在替代文本里重复旁边已经可见的标题、作者和序号；多图需说明当前位置。
- 放大查看器保留关闭出口、焦点/系统返回和缩放后的平移边界，不能把核心信息锁在手势里。

## 帖子列表封面的业务映射

帖子列表仍使用 `cover` 角色，静态预览与动画播放保持同一裁切框。列表默认用第一帧静态预览；点击封面沿用卡片的帖子详情导航，完整来源在详情中查看，不为封面新增一套查看器。

业务列表采用可视区域自动播放：封面可见比例达到 50% 即加载并播放，不等待滚动停稳，不限制同屏并播数量；激活后只要仍有可见部分（大于 0%）就保持播放，完全离屏才停止。完全离屏后再次达到启播阈值时从头播放，并复用仍有效的字节缓存。可见比例、播放状态和省流量偏好由 Web/Mobile 的帖子列表业务模块集中定义与测试；这里记录帖子列表约定，不新增或覆盖 Foundation 的全局动效数值。首页、搜索、收藏、个人主页和复用同一帖子卡片的标签列表遵循同一业务规则。

策略记录：此前候选采用“滚动停稳后只播放最接近可视区域中心的一张”，现已由上述可视区域自动播放策略替换。原策略的验收结果保留为历史证据，不代表新策略的性能表现。

- 尚未达到启播条件的动画封面只请求生产者明确提供的静态预览；不能先加载完整动画再遮住，也不能靠扩展名识别动画。达到阈值后只加载该封面所需的一档动画，不预取离屏动画。
- 生产者未提供可信静态预览或动画属性时，列表保留封面占位和帖子导航，不尝试猜测衍生 URL 或下载来源探测。进入详情后仍按正文图片规则展示来源。
- 已知静态图片可以直接使用生产者明确返回的安全静态来源。静态预览失败时保持占位，不能回退到可能是动画的完整来源。
- 页面或 Tab 隐藏、进入后台、被覆盖、路由转场、减少动态效果或用户选择省流量时，停止动画呈现并恢复静态预览；客户端应释放或停止对应的解码工作。滚动本身不停止仍可见的已激活动画。
- Web 使用原生图片与浏览器 HTTP 缓存；同 URL 的多个动画实例可能共享浏览器时钟，另一实例挂载或重入时允许偶尔同步重启。不同 URL 的实例仍须互不重启。Mobile 使用各实例独立 codec，不采用此例外。Web 慢导航等待期间旧页仍完整可见时保持原实例；提交或实际隐藏、覆盖时清理旧实例，不因点击意图或被取消的导航重启。
- 动画不改变图片布局或卡片点击语义，播放遵循源文件时长与有限／无限循环设置；除上述 Web 同 URL 例外外，普通布局更新或滚动不能重启尚在可见区域的动画。第一帧为空白或透明时也不擅自改选其他帧。
- 来源地址、动画判定和静态预览地址来自后端已提交的帖子列表生产者契约；旧字段的存在不能视为已具备动画播放元数据。
- 列表动画可优先使用生产者明确提供的预览变体；完整来源地址继续关联原媒体和详情导航。客户端按实际裁切框与屏幕像素密度选择最小足够清晰的有效变体，只请求被选中的一档；不能从命名猜测其他尺寸或提前下载所有档位。
- 动画预览保留完整时间线、帧时长、循环和透明合成语义；缩小尺寸不改变播放速度。未提供有效变体时，只有已确认动画且可信首帧可用的内容才允许沿用受控来源播放，未知内容继续占位。
- 缓存只复用符合有效期和可见性边界的资源。公开不可变资源可以采用稳定版本地址与HTTP长期缓存；账户切换与退出须撤销旧账户的播放状态及客户端自行维护的账户缓存作用域；公开资源的浏览器HTTP缓存按其有效期复用。缓存不能成为访问权限依据，也不保证已下载公开内容可以即时撤回。

多播性能按可见数量、素材大小及冷缓存／内存重入／磁盘重入分别验收，同时观察快速往返时的取消、重请求和资源释放。编码缓存容量不等于活动 codec、解码帧与在途响应的总内存上限；预览节省传输也不代表并播没有解码或绘制成本。

组件级合成素材与受控网络测量不能替代完整业务页面、实际耗电或屏幕掉帧率验收；首帧绘制、进程内存采样、服务端写出字节和设备实际收到字节须区分。Web 减少几何测量次数只证明调度开销下降，不能据此认定长列表流畅。具体环境、样本和限制见 [Web 验收记录](https://github.com/morenk/wenyousite-frontend/pull/10)、[Web 测量边界](https://github.com/morenk/wenyousite-frontend/blob/68bbfa2e87956214b3de4cfbbd7b0b8ff5a73f28/docs/modules/home.md)、[Web 持久性能报告](https://github.com/morenk/wenyousite-frontend/blob/aef749d7c16789a3b388f275fe8d5c237e20a518/docs/cover-playback-performance.md)及 [Mobile 验收记录](https://github.com/morenk/wenyousite-mobile/pull/14)，本共享说明不复制随候选变化的测量数值。

这属于既有 `cover` 角色、`neverDeriveVariantUrls`、`failureKeepsContext` 和减少动态效果原则的业务接入说明。机器角色与生成 API 保持不变；不要求消费者改为依赖未发布的 Foundation 提交。

## 平台映射

Web 用模态 lightbox，支持关闭按钮、Esc、遮罩关闭、适应屏幕、原始尺寸、滚轮和显式缩放控件。Flutter 用全屏路由，支持应用返回、系统返回、双击/捏合缩放和平移；只有未放大时才响应下滑关闭。两端不追求同一动画或像素，只保证完整查看、退出和状态语义一致。

具体角色、状态及平台动作的机器事实源为 `contracts/foundation.v1.json` 的 `experiences.images`。

## 动态帖动态图播放

机器规则为 `experiences.images.momentPlayback`；`contracts/fixtures/moment-playback.json` 固定跨端验收输入与预期。此规则覆盖动态配图、评论、楼中楼图片与动态表情，不改变主题帖和发布编辑器。

| 场景 | 播放条件 | 不满足时 |
| --- | --- | --- |
| 发现、关注、搜索、个人主页、收藏列表 | 永不播放，点击进入详情 | 服务端静态派生图；失败或缺失显示占位 |
| 详情轮播 | 当前图片、可见、页面活跃且前台 | 卸载动画资源，恢复静态图 |
| 详情评论、楼中楼及动态表情 | 所有可见项均可播放，允许同屏多张 | 离屏卸载动画资源 |
| 全屏查看 | 仅当前可见图片，底层详情暂停 | 关闭后恢复符合条件的详情播放 |

组件必须显式接收是否允许播放，再与可见区域、页面活跃状态、浏览器标签可见性或 App 前台状态共同决定动画资源是否挂载。仅用 CSS 隐藏图片或隐藏已加载的 Flutter 动画不能视为停止。离开详情或返回列表、进入后台或隐藏标签时停止，重新可见时可从头播放，不要求续播进度。

静态预览和播放资源必须分别选择。GIF 使用生产者提供的 `thumbnailUrl` 静态派生图，播放使用 `url` 原图；动态表情静止时使用服务端缩略图，播放时使用动画资产 `url`。沿用现有 `animated` 与 `contentType` 判定，不根据文件后缀判断或拼接派生地址。列表及所有静止状态不得以动画原图作为缩略图失败回退；列表不得预取动画，即使悬停、聚焦或滚动停稳也不能触发。没有静态派生资源的历史媒体保留占位，本次不新增高清首帧和历史回填。

动画失败后展示静态图，静态图也不可用则占位，并提供显式重试。失败状态应跨轮播切换、离屏及前后台切换保留，直至用户重试或媒体身份变化，避免生命周期变化导致自动重试循环。保存仍使用原图并保留 GIF 动画；查看器继续遵守完整显示、缩放及退出规则。

用例中的 `pageActive` 表示当前页面未离开，`foreground` 表示 App 前台或浏览器标签可见；`visible` 表示图片在可见区域，`current` 表示轮播或全屏选中项，`fullscreenOpen` 用于暂停底层详情，`playbackAllowed` 为调用方授权。`staticAvailable` 和 `animationFailed` 描述已知资源状态，用例并不替代真实多帧 GIF 的视觉与网络验收。

本次是已发布 6.9.0 之后的候选规则；现有 v6.9.0 Tag 不包含此规则。本次仅提交共享规则和用例，不提升契约版本、不创建 Tag 或 Release。消费者可将已提交文档作为评审依据，但不得在运行时锁定未发布提交；未来需要升级 Foundation 包时，须先由用户明确决定发布，再通过独立升级提交消费正式 Tag。
